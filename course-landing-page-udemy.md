Về khoá học Claude 101 - From Zero to Hero - Tiếng Việt

Bạn đang tò mò về Claude, muốn biết AI này khác gì so với các công cụ khác, hoặc bạn đã nghe nói tới Claude Code nhưng chưa biết bắt đầu từ đâu. Bạn là Developer, Tester, DevOps Engineer, Cloud Engineer hay Project Manager và muốn ứng dụng Claude để tăng tốc công việc hằng ngày. Khoá học này chính xác dành cho bạn!

Khoá học không yêu cầu bất kỳ kiến thức nền tảng nào. Đi từ những khái niệm cơ bản nhất — Claude là gì, hệ sinh thái sản phẩm gồm những gì, cách viết prompt hiệu quả — cho tới các chủ đề nâng cao hơn như Claude Skills, Sub-agent, Model Context Protocol (MCP), Hooks và phương pháp phát triển phần mềm Spec-Driven Development kết hợp Claude Code.

Khoá học thiết kế đan xen giữa lý thuyết và thực hành xuyên suốt mọi chương. Sau mỗi phần lý thuyết đều có bài lab thực hành ngay, giúp bạn không chỉ hiểu khái niệm mà còn tự tay thao tác, áp dụng được vào công việc thực tế thay vì chỉ dừng lại ở việc "chat" với AI.

Đối tượng phù hợp với khoá học

Khoá học phù hợp với tất cả mọi người muốn tìm hiểu về Claude, không yêu cầu kiến thức đầu vào. Đặc biệt phù hợp với:

Developer muốn dùng Claude Code để khởi tạo project, đọc hiểu codebase lạ, viết tính năng mới, refactor và debug nhanh hơn.

DevOps/Cloud Engineer muốn dùng Claude hỗ trợ viết Infrastructure as Code (Terraform), script tự động hoá và phân tích log sự cố.

Tester/QA muốn dùng Claude sinh test case, viết test tự động và hỗ trợ viết bug report.

Project Manager muốn dùng Claude soạn thảo tài liệu dự án, tóm tắt cuộc họp và theo dõi tiến độ.

Bất kỳ ai làm việc trong lĩnh vực IT muốn đưa Claude vào quy trình làm việc hằng ngày một cách bài bản, an toàn và hiệu quả.

Nội dung chính của khoá học

Khoá học gồm 11 section, tổng thời lượng khoảng 13-15 giờ, đi từ nền tảng đến ứng dụng chuyên sâu:

Làm quen với hệ sinh thái Claude: Claude Desktop App, Claude Code, các dòng model (Haiku, Sonnet, Opus), nguyên tắc viết prompt hiệu quả và mẹo tối ưu chi phí.

Claude Skills & Agent: tự tạo Skill tái sử dụng và Sub-agent chuyên biệt hoá cho từng tác vụ cụ thể.

Claude Code cho Developer: khởi tạo project từ zero (Next.js, Prisma, MySQL), đọc hiểu codebase sẵn có, implement tính năng mới, refactor và viết unit test.

Claude cho DevOps & Cloud Engineer: sinh và review Terraform, viết script tự động hoá, phân tích log lỗi.

Claude cho Tester/QA: sinh test case, viết test tự động, viết bug report chuyên nghiệp.

Claude cho Project Manager: soạn tài liệu dự án, tóm tắt cuộc họp, quản lý ngữ cảnh dự án bằng Claude Projects.

Model Context Protocol (MCP): kết nối Claude Code với codebase phức tạp (CodeGraph) và database (MySQL) để kiểm chứng dữ liệu.

Claude Code Hooks: tự động hoá vòng đời làm việc, format code tự động, cảnh báo an toàn.

Spec-Kit Framework: phương pháp Spec-Driven Development, phát triển tính năng có kiểm soát, giảm rủi ro "vibe coding".

Toàn bộ lý thuyết đều gắn liền với bài lab thực hành ngay sau đó, xuyên suốt trên một project mẫu (ứng dụng quản lý chi tiêu - Expense Management) để bạn thấy rõ tính liên kết giữa các chương.

Mục tiêu sau khi hoàn thành khoá học

Sau khoá học này bạn sẽ:

Tự tin sử dụng thành thạo Claude Desktop App và Claude Code trong công việc hằng ngày.

Biết cách viết prompt hiệu quả, tối ưu chi phí khi vận hành Claude.

Tự xây dựng được Skill và Sub-agent phục vụ công việc chuyên biệt của riêng mình.

Ứng dụng được Claude Code vào vòng đời phát triển phần mềm thực tế: từ tìm hiểu code, viết tính năng, đến refactor và tạo Pull Request.

Kết nối Claude Code với hệ thống bên ngoài qua MCP (codebase, database) và tự động hoá quy trình làm việc bằng Hooks.

Áp dụng phương pháp Spec-Driven Development để phát triển phần mềm có kiểm soát, dễ kiểm chứng.

Có lộ trình cá nhân hoá để tiếp tục ứng dụng Claude vào công việc thực tế sau khoá học.

Điểm khác biệt của khoá học

Được hỗ trợ trong suốt quá trình học: mình thường xuyên theo dõi và trả lời Q&A trên Udemy, đồng thời có group hỗ trợ riêng cho học viên đã mua khoá học để giải đáp thắc mắc kỹ thuật.

Xuyên suốt trên một project thực tế: các bài lab được thiết kế liên kết với nhau trên cùng một ứng dụng mẫu, giúp bạn thấy rõ Claude được áp dụng vào một quy trình làm việc thực tế thay vì các ví dụ rời rạc.

Nội dung dành riêng cho từng vai trò IT: có hẳn các chương riêng cho Developer, DevOps/Cloud Engineer, Tester/QA và Project Manager, giúp bạn áp dụng đúng vào công việc của mình.
