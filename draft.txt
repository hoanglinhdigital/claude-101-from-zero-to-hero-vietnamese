# Tạo các Skill và Agent cần thiết.
Hướng dẫn học viên sử dụng tính năng Skill creator, Agent creator sẵn có của Claude CLi để tạo các Skill & Agent sau:
## Danh sách các skill cần tạo:
- Skill Frontend Coding giúp thống nhất phong cách thiết kế, responsive, bảng màu, font chữ, emoji, sử dụng Lucide icon, sử dụng Tailwindcss, hạn chế sử dụng css class tự chế. Tách component khi có thể để tăng tính tái sử dụng, lưu vào /src/app/components
- Skill API Design giúp tạo API theo chuẩn OpenAPI 3.0 swagger theo từng cụm chức năng như account, analysis, auth, category, contact,currency, home, transaction
- Skill Backend Coding giúp thống nhất cách phân chia APi path, lưu vào /src/app/api/<api-group-name>/<api-path>. Thống nhất cách thiết kế method: GET, POST, PUT, DELETE,... Cách thiết kế và implement query param. Cách query database.
- Skill Database Design giúp tạo Prisma model theo các quy tắc: không hard delete, chi tiêu Ammount/money sử dụng kiểu Decimal, không sử dụng kiểu float, Enum được định nghĩa trong Prisma, không sử dụng Free string, ForeignKey (FK) phải có @relation một cách tường minh. field bắt buộc cho mọi entity: id: cuid()/uuid(). createdAt, updatedAt, isDeleted. Naming Conventions: Table: lowercase (user, expense, category). Field: camelCase (createdAt, userId). FK: {model}Id (userId, categoryId). Index: idx_{table}_{field}. Thiết kế Index Bắt buộc phải ưu tiên tốc độ truy vấn vì đây là 1 app có hàng triệu người dùng, nếu bất kỳ query nào có khả năng bị chậm khi số lượng user tăng, cần cân nhắc tối ưu và add thêm index.

## Danh sách các Sub-Agent cần tạo:
- API Testing: Sub-agent có nhiệm vụ tạo ra các script k6 bổ sung vào thư mục `test`, được gọi lại mỗi khi Agent chính làm xong một task coding (Frontend/backend) để tạo và chạy các testcase tương ứng.
- Database Migrate: Sub-agent có nhiệm vụ chạy lệnh prisma migrate và prisma seed (nếu cần), để migrate và khởi tạo lại data mẫu khi có thay đổi.
