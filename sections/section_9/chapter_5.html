9. Claude Code Hooks / Lab - Cấu hình Hook Stop gửi thông báo
Tái sử dụng project: Bài lab này tiếp tục dùng project D:\lab-expense-management đã dùng ở bài Lab trước (Chapter 4). Có thể giữ nguyên Hook PostToolUse đã cấu hình, bài lab này chỉ thêm một Hook mới cho event Stop.

Mục tiêu

  • Cấu hình một Hook Stop trong settings.json, tự động chạy khi Claude Code hoàn thành một tác vụ/phiên trả lời.
  • Hook vừa ghi log (timestamp + tên project) vào file, vừa hiển thị popup thông báo trên màn hình Windows.
  • Kiểm chứng bằng cách giao một tác vụ cho Claude Code, chờ hoàn thành, xác nhận thấy popup xuất hiện và có dòng log mới trong file.

Khi Claude Code phát sinh event Stop (hoàn thành tác vụ), Hook chạy một script PowerShell vừa ghi log vào file vừa hiện popup thông báo ngay trên màn hình, giúp User biết ngay mà không cần canh terminal.

Yêu cầu trước khi bắt đầu

  • Máy Windows có giao diện desktop — popup dùng Windows Forms nên chỉ hiển thị được trên máy có phiên đăng nhập giao diện (không áp dụng cho máy chủ headless/kết nối SSH không màn hình).
  • Claude Code CLI đã cài đặt và đăng nhập thành công.
  • PowerShell có thể chạy được file .ps1 — bài lab dùng cờ -ExecutionPolicy Bypass ngay trong command của Hook nên không cần đổi execution policy chung của máy.
  • Project D:\lab-expense-management đã có sẵn (tái sử dụng từ bài Lab trước).

Các bước thực hành

  1. Bước 1: Tạo thư mục chứa script Hook

    Tạo thư mục riêng để lưu script PowerShell mà Hook sẽ gọi tới.

    cd D:\lab-expense-management
mkdir .claude\hooks -Force
  2. Bước 2: Tạo file script notify-stop.ps1

    Script này ghi một dòng log kèm timestamp + tên project vào file hook-log.txt, sau đó hiện popup thông báo bằng Windows Forms.

    @'
$logFile = "D:\lab-expense-management\.claude\hooks\hook-log.txt"
$timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
$projectName = "lab-expense-management"

Add-Content -Path $logFile -Value "$timestamp - Claude Code da hoan thanh tac vu trong project: $projectName"

Add-Type -AssemblyName System.Windows.Forms
[System.Windows.Forms.MessageBox]::Show(
  "Claude Code da hoan thanh tac vu trong project $projectName!",
  "Claude Code - Thong bao",
  [System.Windows.Forms.MessageBoxButtons]::OK,
  [System.Windows.Forms.MessageBoxIcon]::Information
)
'@ | Set-Content -Path .claude\hooks\notify-stop.ps1 -Encoding utf8

    Nội dung file tương đương như sau:

    .claude/hooks/notify-stop.ps1# Ghi log + hien popup khi Claude Code hoan thanh tac vu
$logFile = "D:\lab-expense-management\.claude\hooks\hook-log.txt"
$timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
$projectName = "lab-expense-management"

Add-Content -Path $logFile -Value "$timestamp - Claude Code da hoan thanh tac vu trong project: $projectName"

Add-Type -AssemblyName System.Windows.Forms
[System.Windows.Forms.MessageBox]::Show(
  "Claude Code da hoan thanh tac vu trong project $projectName!",
  "Claude Code - Thong bao",
  [System.Windows.Forms.MessageBoxButtons]::OK,
  [System.Windows.Forms.MessageBoxIcon]::Information
)
  3. Bước 3: Khai báo Hook Stop trong .claude/settings.json

    Cập nhật (hoặc tạo mới, nếu chưa có PostToolUse từ bài Lab trước) file settings.json, thêm event Stop gọi script vừa tạo. Event Stop không gắn với một tool cụ thể nên không cần khai báo "matcher".

    @'
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "npx prettier --write ." }
        ]
      }
    ],
    "Stop": [
      {
        "hooks": [
          { "type": "command", "command": "powershell -NoProfile -ExecutionPolicy Bypass -File \"D:\\lab-expense-management\\.claude\\hooks\\notify-stop.ps1\"" }
        ]
      }
    ]
  }
}
'@ | Set-Content -Path .claude\settings.json -Encoding utf8

    Nội dung file tương đương như sau (giữ lại Hook PostToolUse ở bài Lab trước, thêm Hook Stop mới):

    .claude/settings.json{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "npx prettier --write ." }
        ]
      }
    ],
    "Stop": [
      {
        "hooks": [
          { "type": "command", "command": "powershell -NoProfile -ExecutionPolicy Bypass -File \"D:\\lab-expense-management\\.claude\\hooks\\notify-stop.ps1\"" }
        ]
      }
    ]
  }
}
  4. Bước 4: Khởi động lại Claude Code để áp dụng cấu hình mới

    Thoát phiên hiện tại (nếu đang mở) và mở lại trong đúng thư mục project.

    cd D:\lab-expense-management
claude
  5. Bước 5: Giao một tác vụ cho Claude Code và chờ hoàn thành

    Giao một yêu cầu đủ để Claude Code xử lý xong và dừng lại (kích hoạt event Stop) — ví dụ yêu cầu tóm tắt cấu trúc project hiện tại.

    Tóm tắt ngắn gọn cấu trúc thư mục hiện tại của project và liệt kê các API route đang có.
  6. Bước 6: Xác nhận popup xuất hiện

    Ngay khi Claude Code trả lời xong (event Stop kích hoạt), một cửa sổ MessageBox sẽ hiện lên trên màn hình với nội dung thông báo đã cấu hình trong script. Nhấn OK để đóng popup.

  7. Bước 7: Xác nhận dòng log mới trong file

    Kiểm tra file log để thấy dòng mới vừa được ghi, kèm đúng timestamp thời điểm tác vụ vừa hoàn thành.

    Get-Content "D:\lab-expense-management\.claude\hooks\hook-log.txt" -Tail 5

✅ Kết quả mong đợi

Ngay sau khi Claude Code hoàn thành tác vụ ở Bước 5, một popup Windows hiện lên thông báo hoàn thành, và file hook-log.txt có thêm một dòng mới với timestamp trùng thời điểm popup xuất hiện.

Troubleshoot

Lỗi: Không thấy popup hiện lên, dù Claude Code đã trả lời xong.
Nguyên nhân: Có thể phiên Claude Code đang chạy trong một môi trường không có giao diện desktop (vd remote SSH không màn hình), hoặc script có lỗi cú pháp nên PowerShell dừng trước khi tới lệnh hiện popup.
Giải pháp: Chạy thử trực tiếp script bằng lệnh powershell -File .claude\hooks\notify-stop.ps1 ngoài Claude Code để kiểm tra lỗi cụ thể; đảm bảo đang chạy trên máy Windows có phiên đăng nhập giao diện.
Lỗi: PowerShell báo cannot be loaded because running scripts is disabled on this system.
Nguyên nhân: Execution Policy của máy đang chặn chạy file .ps1. Cờ -ExecutionPolicy Bypass trong command của Hook thường đã xử lý được việc này, nhưng một số máy công ty có Group Policy chặn ở mức cao hơn.
Giải pháp: Kiểm tra lại command trong settings.json có đúng cờ -ExecutionPolicy Bypass chưa; nếu vẫn bị chặn do chính sách công ty, cần liên hệ bộ phận IT để được hỗ trợ.
Lỗi: File log không được tạo, dù popup vẫn hiện lên.
Nguyên nhân: Thư mục chứa file log (.claude/hooks/) chưa tồn tại, hoặc đường dẫn trong script không khớp với đường dẫn thực tế trên máy.
Giải pháp: Kiểm tra lại thư mục đã được tạo ở Bước 1, và đường dẫn trong notify-stop.ps1 khớp đúng vị trí project trên máy đang dùng.
Lưu ý: Cách event Stop được kích hoạt chính xác (mỗi lượt model dừng trả lời hay chỉ khi toàn bộ phiên kết thúc) có thể khác nhau theo phiên bản Claude Code. Nếu thấy popup hiện nhiều lần hơn dự kiến, hãy tham khảo tài liệu chính thức tại docs.claude.com để hiểu đúng thời điểm kích hoạt trong phiên bản đang dùng.

Dọn dẹp resource

Bài lab này không tạo resource trên Cloud, chỉ thêm file cấu hình và script cục bộ. Không bắt buộc phải xoá gì — chỉ cần gỡ Hook nếu không muốn tiếp tục nhận popup mỗi lần dùng Claude Code trên project này.

Nếu muốn tạm ngưng Hook Stop mà không xoá project, xoá phần "Stop" trong .claude/settings.json (giữ lại "PostToolUse" nếu vẫn muốn dùng):

.claude/settings.json (da tat Hook Stop){
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          { "type": "command", "command": "npx prettier --write ." }
        ]
      }
    ]
  }
}

Xoá file log nếu không muốn giữ lại (tuỳ chọn):

Remove-Item "D:\lab-expense-management\.claude\hooks\hook-log.txt" -Confirm:$false
Quan trọng: Không xoá thư mục D:\lab-expense-management — project này còn được dùng lại ở các Section khác. Chỉ dọn phần cấu hình Hook nếu không muốn giữ.
