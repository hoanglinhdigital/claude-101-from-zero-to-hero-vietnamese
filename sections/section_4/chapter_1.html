4. Claude Code cho Developer / Giới thiệu chương

Giới thiệu

Chương này giúp các bạn hiểu & áp dụng Claude Code vào quy trình phát triển phần mềm hàng ngày của một Developer: khởi tạo project từ đầu, tổ chức quy tắc làm việc, đọc hiểu codebase sẵn có, thêm tính năng mới kèm unit test, viết API testing, và tích hợp với Git để review pull request tự động. Toàn bộ chương xoay quanh một project thực hành xuyên suốt — ứng dụng Quản lý chi tiêu (Expense Management) xây dựng bằng Next.js + Prisma + MySQL — giúp các bạn trải nghiệm trọn vẹn vòng đời phát triển với sự hỗ trợ của Claude Code.

Mục tiêu chương

  • Nắm được quy trình làm việc chuẩn với Claude Code: Explore → Plan → Code → Verify.
  • Dùng Claude Code khởi tạo một project mới với tech stack Next.js + Prisma + MySQL trong thời gian ngắn.
  • Biết cách tổ chức project và định nghĩa quy tắc làm việc cho Claude Code thông qua file CLAUDE.md.
  • Nâng cấp quy trình làm việc bằng Skill và Sub-Agent để tái sử dụng cho các tác vụ lặp lại.
  • Yêu cầu Claude Code thêm tính năng mới và tự viết unit test đi kèm.
  • Dùng Claude Code viết API testing và tích hợp vào workflow phát triển.
  • Hiểu giới hạn và rủi ro khi để Claude Code thao tác trực tiếp với Git.
  • Dùng Claude Code hỗ trợ review pull request tự động.
  • Triển khai hệ thống đã xây dựng lên Cloud AWS.
