4. Claude Code cho Developer / Lab - Khám phá & tóm tắt kiến trúc một repository có sẵn

Mục tiêu

  • Dùng Claude Code để đọc và tóm tắt kiến trúc một repository mã nguồn mở lần đầu tiếp cận, không cần đọc thủ công toàn bộ code.
  • Biết cách đặt prompt yêu cầu Claude Code tóm tắt entry point, luồng dữ liệu và các module chính của một codebase lạ.
  • Rút ra được bức tranh tổng quan kiến trúc trong thời gian ngắn — kỹ năng quan trọng khi tham gia một project/team mới.

Claude Code tự đọc file cấu hình, entry point và các module chính của repository, sau đó tổng hợp lại thành bản tóm tắt kiến trúc dễ hiểu cho người mới tiếp cận.

Yêu cầu trước khi bắt đầu

  • Claude Code CLI đã cài đặt và đăng nhập thành công (xem lại Section 2).
  • Git đã được cài đặt trên máy (git --version chạy được).
  • Node.js phiên bản 18 trở lên (không bắt buộc chạy được project, chỉ cần cho việc xem package.json/cấu trúc).
  • Terminal: PowerShell hoặc Windows Terminal.
  • Kết nối Internet để clone repository.

Các bước thực hành

  1. Bước 1: Clone repository mẫu

    Bài lab này dùng Express.js — một framework Node.js phổ biến, mã nguồn gọn, cấu trúc rõ ràng, phù hợp để luyện kỹ năng đọc hiểu codebase lạ. Có thể thay bằng bất kỳ repository Next.js/Node.js mã nguồn mở khác mà học viên quan tâm.

    mkdir D:\lab-explore-repo
cd D:\lab-explore-repo
git clone https://github.com/expressjs/express.git
cd express
  2. Bước 2: Khởi động Claude Code trong thư mục repository 
    claude
  3. Bước 3: Yêu cầu tóm tắt tổng quan project

    Bắt đầu bằng một prompt tổng quát để Claude Code đọc package.json, README và cấu trúc thư mục cấp cao nhất.

    Đọc package.json, README.md và cấu trúc thư mục cấp cao nhất của repository này. Tóm tắt: (1) project này làm gì, (2) các dependency chính và vai trò của chúng, (3) entry point chính của thư viện/ứng dụng nằm ở file nào.
  4. Bước 4: Yêu cầu tóm tắt luồng dữ liệu chính

    Đi sâu hơn vào cách các thành phần chính phối hợp với nhau khi xử lý một request/tác vụ điển hình.

    Dựa trên entry point vừa tìm được, mô tả luồng xử lý chính khi có một HTTP request đi vào: request đi qua những module/hàm nào theo thứ tự, middleware được áp dụng ở đâu, và response được trả về như thế nào. Vẽ giúp một sơ đồ Mermaid flowchart minh hoạ luồng này.
  5. Bước 5: Yêu cầu liệt kê các module chính và trách nhiệm 
    Liệt kê các file/module quan trọng nhất trong thư mục lib/ (hoặc thư mục source chính), mỗi module nêu rõ trách nhiệm chính (một câu ngắn) và các module khác mà nó phụ thuộc vào hoặc được gọi từ đâu.
  6. Bước 6: Yêu cầu định hướng nếu cần thêm một tính năng nhỏ

    Đây là bước hữu ích nhất trong thực tế — xác nhận Claude Code đã hiểu đúng kiến trúc bằng cách hỏi nó gợi ý điểm bắt đầu cho một thay đổi giả định.

    Nếu muốn thêm một middleware mới áp dụng cho mọi route (ví dụ middleware ghi log thời gian xử lý request), nên bắt đầu sửa/đọc ở file nào trước tiên? Giải thích ngắn gọn vì sao.
  7. Bước 7 (tuỳ chọn): Lưu lại bản tóm tắt thành file

    Yêu cầu Claude Code ghi lại toàn bộ nội dung tóm tắt đã trao đổi thành một file Markdown để tham khảo lại sau, không cần đọc lại toàn bộ hội thoại.

    Tổng hợp toàn bộ nội dung đã tóm tắt ở trên (tổng quan project, luồng xử lý request, danh sách module chính) thành một file ARCHITECTURE-SUMMARY.md ở gốc thư mục hiện tại.

✅ Kết quả mong đợi

Sau 5-6 prompt, học viên có được bức tranh tổng quan về cách một codebase quen được tổ chức: entry point, luồng xử lý chính, module quan trọng nhất — mà không cần tự đọc từng file một cách thủ công. File ARCHITECTURE-SUMMARY.md (nếu thực hiện Bước 7) có thể dùng lại làm tài liệu tham khảo nhanh cho lần sau.

Troubleshoot

Lỗi: git clone báo lỗi timeout hoặc không kết nối được.
Nguyên nhân: Mạng công ty/proxy chặn kết nối đến GitHub, hoặc kết nối Internet không ổn định.
Giải pháp: Kiểm tra lại cấu hình proxy của Git (git config --get http.proxy), thử đổi sang mạng khác, hoặc tải repository dưới dạng file ZIP trực tiếp từ trang GitHub rồi giải nén thủ công.
Lỗi: Bản tóm tắt của Claude Code chưa chính xác hoặc bỏ sót phần quan trọng.
Nguyên nhân: Repository quá lớn, Claude Code chỉ đọc được một phần trong lượt Explore đầu tiên, chưa đủ ngữ cảnh.
Giải pháp: Yêu cầu Claude Code đọc sâu thêm vào đúng thư mục/file còn thiếu (chỉ định rõ đường dẫn), hoặc chia nhỏ câu hỏi thành nhiều lượt tập trung vào từng module một.
Lỗi: Phiên làm việc báo context quá dài, phản hồi chậm dần.
Nguyên nhân: Repository có nhiều file, Claude Code đã đọc và giữ lại quá nhiều nội dung trong context của phiên hiện tại.
Giải pháp: Dùng slash command /compact để rút gọn lịch sử hội thoại trước khi tiếp tục hỏi thêm, giữ lại phần tóm tắt quan trọng.

Dọn dẹp resource

Bài lab này chỉ clone và đọc code trên máy local, không tạo ra resource cloud nào và không phát sinh chi phí ngoài usage theo gói cước Claude đang sử dụng. Có thể xoá thư mục repository đã clone sau khi hoàn thành nếu không cần dùng lại:
Remove-Item -Recurse -Force D:\lab-explore-repo
