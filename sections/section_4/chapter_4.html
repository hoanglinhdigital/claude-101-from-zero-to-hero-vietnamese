4. Claude Code cho Developer / Lab - Khởi tạo project Expense Management (Next.js + Prisma + MySQL)
Project nền cho cả Section 4: Project lab-expense-management được tạo trong bài lab này sẽ được tái sử dụng ở các bài Lab tiếp theo (Chapter 6 - thêm tính năng & unit test, Chapter 7 - refactor & tạo Pull Request) và cả ở Section 8 (MCP Server MySQL). Hãy giữ lại thư mục project sau khi hoàn thành, không xoá đi.

Mục tiêu

  • Dùng Claude Code khởi tạo một project Next.js mới (frontend + backend qua API Routes) trong thời gian ngắn.
  • Tích hợp Prisma ORM kết nối MySQL, chạy MySQL local bằng Docker Compose để làm database demo.
  • Yêu cầu Claude Code implement các tính năng cơ bản cho app Quản lý chi tiêu (Expense Management): CRUD khoản chi tiêu, quản lý danh mục (category), tổng hợp chi tiêu theo tháng.
  • Kiểm chứng kết quả trên trình duyệt sau khi hoàn thành.

Claude Code sinh toàn bộ mã nguồn Next.js (frontend + API routes), cấu hình Prisma ORM để giao tiếp với MySQL chạy trong Docker container local.

Yêu cầu trước khi bắt đầu

  • Claude Code CLI đã cài đặt và đăng nhập thành công (xem lại Section 2).
  • Node.js phiên bản 18 trở lên đã được cài đặt (node -v chạy được).
  • Docker Desktop đã cài đặt và đang chạy trên máy (docker --version chạy được).
  • Terminal: PowerShell hoặc Windows Terminal.
  • Kết nối Internet ổn định để cài package và pull Docker image.

Phần 1: Khởi tạo project qua Claude Code

  1. Bước 1: Tạo thư mục project và khởi động Claude Code

    Đặt tên thư mục cố định lab-expense-management — sẽ dùng lại tên này xuyên suốt các bài lab tiếp theo trong Section 4 và Section 8.

  2. Bước 2: Yêu cầu Claude Code khởi tạo project Next.js + Prisma + MySQL

    Gõ prompt đầy đủ context trong khung nhập lệnh Claude Code — nêu rõ tech stack, cấu trúc mong muốn và yêu cầu tạo Docker Compose cho MySQL.

    Khởi tạo một project Next.js mới trong thư mục hiện tại, dùng TypeScript, Tailwind CSS và App Router. Tích hợp Prisma ORM kết nối MySQL. Yêu cầu cụ thể:
1. Tạo file docker-compose.yml chạy MySQL 8.0 local (container name: expense-mysql, database: expense_db, user: expense_user, password: expense_pass, expose port 3306, có volume lưu data).
2. Tạo file .env chứa DATABASE_URL kết nối đến MySQL container trên.
3. Tạo schema Prisma (prisma/schema.prisma) với 2 model: Category (id, name unique) và Expense (id, title, amount kiểu Decimal, note optional, categoryId liên kết Category, spentAt, createdAt, updatedAt).
4. Sau khi tạo xong, build thử project để đảm bảo không lỗi cấu hình.
  3. Bước 3: Duyệt kế hoạch và xác nhận thực thi

Phần 2: Tham khảo nội dung file cấu hình Claude Code tạo ra

Nội dung dưới đây là ví dụ tham khảo cho những gì Claude Code nên sinh ra ở Bước 2 — dùng để đối chiếu, không cần tạo tay các file này.

docker-compose.ymlservices:
  mysql:
    image: mysql:8.0
    container_name: expense-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: rootpassword
      MYSQL_DATABASE: expense_db
      MYSQL_USER: expense_user
      MYSQL_PASSWORD: expense_pass
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
volumes:
  mysql_data:
.envDATABASE_URL="mysql://expense_user:expense_pass@localhost:3306/expense_db"
prisma/schema.prismadatasource db {
  provider = "mysql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

model Category {
  id        Int       @id @default(autoincrement())
  name      String    @unique
  expenses  Expense[]
  createdAt DateTime  @default(now())
}

model Expense {
  id         Int       @id @default(autoincrement())
  title      String
  amount     Decimal   @db.Decimal(12, 2)
  note       String?
  categoryId Int
  category   Category  @relation(fields: [categoryId], references: [id])
  spentAt    DateTime  @default(now())
  createdAt  DateTime  @default(now())
  updatedAt  DateTime  @updatedAt
}

Phần 3: Chạy MySQL, migrate database và implement tính năng

  1. Bước 5: Khởi động MySQL container bằng Docker Compose

    Chạy lệnh sau ngay trong thư mục project (nơi có file docker-compose.yml).

    docker compose up -d

    Kiểm tra container đã chạy thành công.

    docker ps
CONTAINER ID   IMAGE       ...   PORTS                    NAMES
abc123def456   mysql:8.0   ...   0.0.0.0:3306->3306/tcp   expense-mysql
  2. Bước 6: Chạy Prisma migration để tạo bảng trong database

    Lệnh này đọc prisma/schema.prisma, sinh migration SQL và áp dụng lên MySQL container vừa khởi động.

    npx prisma migrate dev --name init
  3. Bước 7: Yêu cầu Claude Code implement tính năng Quản lý chi tiêu

    Vẫn trong phiên làm việc hiện tại (đã có ngữ cảnh về schema và project), giao tiếp tính năng cần implement — nêu rõ hành vi mong đợi cho từng phần.

    Implement các tính năng cơ bản cho app Quản lý chi tiêu dựa trên schema Prisma đã có:
1. Trang chủ (app/page.tsx) hiển thị danh sách khoản chi tiêu (title, amount, category, spentAt) dạng bảng, sắp xếp mới nhất lên đầu.
2. API route app/api/expenses/route.ts hỗ trợ GET (danh sách) và POST (tạo mới) khoản chi tiêu.
3. API route app/api/expenses/[id]/route.ts hỗ trợ PUT (sửa) và DELETE (xoá) một khoản chi tiêu theo id.
4. API route app/api/categories/route.ts hỗ trợ GET (danh sách) và POST (tạo mới) danh mục.
5. Một form đơn giản trên trang chủ để tạo khoản chi tiêu mới, chọn category từ dropdown.
6. Một API route app/api/expenses/summary/route.ts trả về tổng chi tiêu theo từng tháng (group by tháng-năm của spentAt).
Dùng Prisma Client đã cấu hình sẵn, không cần thêm ORM khác.

Troubleshoot

Lỗi: docker compose up báo lỗi cổng 3306 đã được sử dụng.
Nguyên nhân: Máy đã có một MySQL khác (service cài local hoặc container khác) đang chiếm cổng 3306.
Giải pháp: Đổi mapping cổng trong docker-compose.yml thành ví dụ "3307:3306", cập nhật lại DATABASE_URL trong .env tương ứng port mới, sau đó chạy lại docker compose up -d.
Lỗi: npx prisma migrate dev báo không kết nối được database (Can't reach database server).
Nguyên nhân: Container MySQL chưa khởi động xong hoàn toàn (MySQL cần vài giây để sẵn sàng nhận kết nối sau khi container start), hoặc DATABASE_URL trong .env sai thông tin.
Giải pháp: Chờ khoảng 10-15 giây sau docker compose up -d rồi thử lại; kiểm tra lại user/password/database trong .env khớp với docker-compose.yml.
Lỗi: npm run dev báo cổng 3000 đã được sử dụng.
Nguyên nhân: Có một Next.js dev server khác (từ lab trước) vẫn đang chạy.
Giải pháp: Đóng terminal đang chạy dev server cũ, hoặc chạy npm run dev -- -p 3001 để dùng cổng khác.
