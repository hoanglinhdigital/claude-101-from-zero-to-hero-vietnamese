4. Claude Code cho Developer / Lab - Thêm tính năng mới & viết unit test
Bài lab này tiếp tục dùng project D:\lab-expense-management đã tạo ở Chapter 4. Nếu chưa hoàn thành Chapter 4, hãy quay lại thực hiện trước khi bắt đầu bài lab này.

Mục tiêu

  • Dùng Claude Code thêm một tính năng mới vào project có sẵn: xuất CSV danh sách chi tiêu theo tháng.
  • Yêu cầu Claude Code viết unit test (Jest) cho phần logic của tính năng vừa thêm.
  • Biết cách tách logic thuần (pure function) ra khỏi API route để dễ viết unit test hơn.
  • Chạy test và đọc kết quả để xác nhận tính năng hoạt động đúng ở cả trường hợp bình thường và edge case.

Các bước thực hành

Phần 1: Khởi động lại project

  1. Bước 1: Vào thư mục project, khởi động MySQL và Claude Code 
    cd D:\lab-expense-management
docker compose up -d
claude

Phần 2: Thêm tính năng xuất CSV

  1. Bước 2: Yêu cầu Claude Code thêm tính năng xuất CSV, tách logic thuần riêng

    Nêu rõ ràng buộc quan trọng nhất: logic tạo nội dung CSV phải nằm trong một hàm thuần, không phụ thuộc vào Next.js request/response, để có thể viết unit test dễ dàng.

    Thêm tính năng xuất CSV danh sách chi tiêu theo tháng cho project. Yêu cầu cụ thể:
1. Tạo file lib/csv-export.ts chứa hàm thuần buildExpensesCsv(expenses: Expense[]): string — nhận vào danh sách khoản chi tiêu (đã có category name kèm theo), trả về nội dung CSV dạng string với header "Ngày,Danh mục,Tiêu đề,Số tiền". Hàm này KHÔNG được gọi Prisma hay import bất cứ gì liên quan Next.js, chỉ nhận dữ liệu qua tham số và trả về string.
2. Xử lý đúng trường hợp title hoặc category name có chứa dấu phẩy (escape bằng dấu ngoặc kép theo chuẩn CSV).
3. Nếu danh sách rỗng, trả về CSV chỉ có dòng header, không lỗi.
4. Tạo API route app/api/expenses/export/route.ts, nhận query param "month" (định dạng YYYY-MM, optional), lấy dữ liệu từ Prisma theo tháng đó (hoặc toàn bộ nếu không truyền month), gọi buildExpensesCsv() để tạo nội dung, trả về response với Content-Type "text/csv" và header Content-Disposition để browser tải file xuống.
5. Thêm một nút "Xuất CSV" trên trang chủ (app/page.tsx), gọi route trên và tải file khi bấm.
  2. Bước 3: Duyệt kế hoạch và xác nhận thực thi

    Đọc qua các file Claude Code dự kiến tạo/sửa (lib/csv-export.ts, app/api/expenses/export/route.ts, app/page.tsx) trước khi cho phép ghi thay đổi.

Phần 3: Yêu cầu viết unit test

  1. Bước 4: Yêu cầu cài đặt và cấu hình Jest (nếu project chưa có) 
    Kiểm tra project đã có Jest chưa. Nếu chưa, cài đặt và cấu hình Jest cho project Next.js + TypeScript này (dùng ts-jest hoặc next/jest, tuỳ cách nào phù hợp hơn với cấu hình hiện tại), thêm script "test": "jest" vào package.json.
  2. Bước 5: Yêu cầu viết unit test cho hàm buildExpensesCsv()

    Nêu rõ các case cần bao phủ: happy path, escape dấu phẩy, danh sách rỗng — để Claude Code không bỏ sót edge case.

    Viết unit test cho hàm buildExpensesCsv() trong lib/csv-export.ts, đặt tại __tests__/csv-export.test.ts. Bao phủ tối thiểu các case:
1. Danh sách có 2-3 khoản chi tiêu bình thường -> đúng số dòng, đúng thứ tự cột, đúng giá trị.
2. Một khoản chi tiêu có title hoặc category chứa dấu phẩy (vd "Ăn uống, giải trí") -> phải được escape đúng bằng dấu ngoặc kép, không làm lệch cột khi mở bằng Excel.
3. Danh sách rỗng -> trả về đúng 1 dòng header, không có dòng dữ liệu, không throw lỗi.
4. Số tiền có phần thập phân (vd 125000.50) -> hiển thị đúng định dạng số trong CSV.
Chạy thử test sau khi viết xong để xác nhận toàn bộ pass.
  3. Bước 6: Chạy test và đọc kết quả

    Tự chạy lại lệnh test để xác nhận độc lập, không chỉ tin vào báo cáo của Claude Code.

    npm test
PASS  __tests__/csv-export.test.ts
  buildExpensesCsv
    ✓ tạo đúng CSV với danh sách chi tiêu bình thường
    ✓ escape đúng giá trị chứa dấu phẩy
    ✓ trả về CSV chỉ có header khi danh sách rỗng
    ✓ giữ đúng định dạng số thập phân
  4. Bước 7: Kiểm tra tính năng trên browser

    Chạy dev server và thử bấm nút "Xuất CSV" để xác nhận file được tải xuống đúng với dữ liệu thực tế trong database.

    npm run dev

    Mở http://localhost:3000, bấm nút Xuất CSV, mở file vừa tải xuống bằng Excel hoặc Notepad để kiểm tra nội dung đúng định dạng.

✅ Kết quả mong đợi

Toàn bộ test case trong __tests__/csv-export.test.ts pass khi chạy npm test. Nút "Xuất CSV" trên trang chủ tải xuống đúng file .csv chứa danh sách chi tiêu, mở được bằng Excel không bị lệch cột dù có dữ liệu chứa dấu phẩy.

Troubleshoot

Lỗi: npm test báo lỗi không nhận cú pháp TypeScript hoặc import module.
Nguyên nhân: Cấu hình Jest chưa khớp với TypeScript/ESM của project Next.js (thiếu preset ts-jest hoặc next/jest).
Giải pháp: Yêu cầu Claude Code kiểm tra lại file jest.config.js/jest.config.ts, đảm bảo dùng đúng preset tương ứng với tsconfig.json hiện có của project.
Lỗi: Test case escape dấu phẩy vẫn fail dù đã sửa code.
Nguyên nhân: Logic escape CSV chưa xử lý đúng chuẩn (cần bọc cả field trong ngoặc kép nếu field chứa dấu phẩy, và escape luôn dấu ngoặc kép có sẵn trong field bằng cách nhân đôi).
Giải pháp: Yêu cầu Claude Code đọc lại chuẩn RFC 4180 cho định dạng CSV và sửa lại hàm buildExpensesCsv() cho đúng, chạy lại npm test để xác nhận.
Lỗi: File CSV tải xuống bị lỗi font tiếng Việt khi mở bằng Excel.
Nguyên nhân: Thiếu BOM (Byte Order Mark) UTF-8 ở đầu file, Excel mặc định đọc sai encoding.
Giải pháp: Yêu cầu Claude Code thêm ký tự BOM (﻿) vào đầu nội dung CSV trước khi trả về response trong API route.
