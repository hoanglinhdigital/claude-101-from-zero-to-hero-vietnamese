6. Claude cho DevOps & Cloud Engineer / Lab - Implement CI/CD trên AWS CodePipeline với Claude
Tiếp nối bài lab trước: Ở Chapter 5, bạn đã dùng Terraform (sinh bởi Claude Code qua skill terraform-aws-generator) để tạo hạ tầng ECS Fargate, ECR, RDS, ALB cho app Quản lý chi tiêu và app đã chạy thành công. Bài lab này đi tiếp: tự động hoá việc build & deploy mỗi khi có commit mới trên Github, bằng AWS CodePipeline (CodeBuild + CodeDeploy) — vẫn giữ nguyên nguyên tắc Claude không bao giờ tự chạy lệnh Terraform/AWS CLI, chỉ sinh code và giải thích.
Cảnh báo chi phí: Bài lab tạo thêm resource AWS thật (CodePipeline, CodeBuild, CodeDeploy, S3 artifact bucket, SNS Topic). Chi phí các dịch vụ này rất nhỏ (CodeBuild tính theo phút build, CodePipeline theo số lượng pipeline active/tháng) nhưng vẫn cần thực hiện Dọn dẹp resource ở cuối bài sau khi hoàn thành để tránh phát sinh phí kéo dài.

Mục tiêu

  • Kết nối Github repository của app Quản lý chi tiêu với AWS thông qua CodeStar Connection.
  • Yêu cầu Claude Code (dùng lại skill terraform-aws-generator đã tạo ở Chapter 5) sinh Terraform cho CodeBuild (build & push Docker image), CodeDeploy (Blue/Green deploy lên ECS), CodePipeline (nối 3 stage Source → Build → Deploy) và SNS Topic báo trạng thái.
  • Thêm buildspec.yml, appspec.yaml, taskdef.template.json vào repository ứng dụng để CodeBuild/CodeDeploy biết cách build và deploy.
  • Tự chạy Terraform để tạo pipeline, sau đó push code lên Github để kiểm chứng pipeline tự động trigger, build, deploy Blue/Green thành công.
  • Dọn dẹp toàn bộ resource CI/CD sau khi hoàn thành.

Các bước thực hành

Phần 1: Kết nối Github với AWS (thao tác thủ công — không dùng Claude/Terraform)

Vì sao bước này không thể tự động hoá: Việc xác thực (OAuth handshake) giữa AWS CodeStar Connection và Github bắt buộc phải xác nhận qua trình duyệt, đăng nhập tài khoản Github của chính bạn. Đây là giới hạn của AWS, không phải giới hạn của Claude Code hay Terraform — nên bước này bạn tự thực hiện hoàn toàn thủ công.
  1. Bước 1: Đẩy source code lên Github (nếu chưa có repo) 
    cd D:\lab-expense-management
git init
git add .
git commit -m "Initial commit - expense management app"
git branch -M main
git remote add origin https://github.com/<github-owner>/lab-expense-management.git
git push -u origin main
  2. Bước 2: Tạo CodeStar Connection bằng AWS CLI

    Lệnh dưới đây tạo connection ở trạng thái PENDING — chưa dùng được ngay.

    
aws codestar-connections create-connection --provider-type GitHub --connection-name expense-dev-github-connection --region ap-northeast-1
#Kết quả trả về JSON có dạng:
{
    "ConnectionArn": "arn:aws:codestar-connections:ap-northeast-1:123456789012:connection/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "Tags": []
}

    Lưu lại ConnectionArn — sẽ dùng làm biến codestar_connection_arn cho Terraform ở Phần 2.

  3. Bước 3: Xác nhận (confirm) connection trên AWS Console

    Mở AWS Console → Developer Tools → Settings → Connections, tìm connection vừa tạo (trạng thái Pending), bấm Update pending connection → chọn Install a new app (nếu chưa từng cài) → đăng nhập Github → cấp quyền cho AWS Connector → chọn đúng repository lab-expense-management → Connect. Sau bước này trạng thái connection chuyển thành Available.

Phần 2: Yêu cầu Claude Code sinh Terraform cho CodePipeline/CodeBuild/CodeDeploy/SNS

  1. Bước 4: Yêu cầu Claude mở rộng module cicd 
    
Dùng skill terraform-aws-generator để thêm module mới "cicd" vào infra/terraform/modules/cicd/, sau đó gọi module
này từ infra/terraform/environments/dev/main.tf. Module cần tạo:

1. S3 bucket lưu artifact cho CodePipeline (versioning + encryption bật sẵn).
2. CodeBuild project: build Docker image từ buildspec.yml, push lên ECR repository đã có (module.storage), IAM Role
   theo least-privilege chỉ đủ quyền push đúng 1 ECR repository.
3. CodeDeploy application + deployment group: deploy Blue/Green lên ECS Service đã có (module.compute), dùng 2 ALB
   listener (prod/test) và 2 Target Group (blue/green) đã có (module.network hoặc module.compute).
4. CodePipeline 3 stage: Source (CodeStarSourceConnection, trigger từ nhánh main), Build (CodeBuild), Deploy
   (CodeDeployToECS).
5. SNS Topic nhận thông báo pipeline Success/Failed qua CodeStar Notifications, subscription email dùng biến
   alert_email (không hardcode).

Biến đầu vào cần khai báo trong terraform.tfvars: github_owner, github_repo, codestar_connection_arn (ARN đã confirm
ở Phần 1), alert_email.

Sau khi sinh xong, liệt kê danh sách file đã tạo/sửa, KHÔNG chạy bất kỳ lệnh terraform nào.
  2. Bước 5: Kiểm tra Claude có tuân thủ đúng Skill không

    Đối chiếu: (1) module mới có nằm đúng infra/terraform/modules/cicd/ không; (2) naming có đúng tiền tố expense-dev-*-01 không; (3) IAM Role của CodeBuild có bị dùng Resource = "*" cho action ECR push không (phải giới hạn đúng 1 repository); (4) Claude có tự ý chạy lệnh terraform nào không.

✅ Kết quả mong đợi

Mỗi lần git push lên nhánh main, CodePipeline tự động chạy đủ 3 stage Source → Build → Deploy mà không cần thao tác thủ công nào khác. CodeDeploy thực hiện Blue/Green — traffic chỉ chuyển sang task mới sau khi health check pass, nếu health check fail thì tự động rollback về task cũ. Email của bạn nhận được thông báo Succeeded hoặc Failed qua SNS sau mỗi lần chạy pipeline.

Troubleshoot

Lỗi: CodePipeline Source stage báo Access denied. Reason:PENDING connection.
Nguyên nhân: Connection tạo bằng CLI ở Phần 1 chưa được confirm thủ công trên Console.
Giải pháp: Quay lại Phần 1, Bước 3 — mở Console, xác nhận connection chuyển sang trạng thái Available trước khi apply Terraform.
Lỗi: CodeBuild fail ở bước docker push với no basic auth credentials.
Nguyên nhân: IAM Role của CodeBuild thiếu quyền ecr:GetAuthorizationToken, hoặc biến môi trường ECR_REPOSITORY_URL chưa được truyền vào CodeBuild project.
Giải pháp: Dán log lỗi cho Claude Code phân tích (chỉ phân tích, không tự sửa và apply lại), kiểm tra lại aws_iam_role_policy.codebuild có đủ action ecr:GetAuthorizationToken ở Resource = "*" (action này bắt buộc phải để *, không giới hạn theo repository được).
Lỗi: CodeDeploy deploy fail với InvalidSignatureException hoặc UnknownContainer: IMAGE1_NAME.
Nguyên nhân: Tên container trong taskdef.template.json không khớp với Image1ContainerName đã khai báo trong CodePipeline Deploy stage.
Giải pháp: Đảm bảo tên container trong containerDefinitions[].name của taskdef.template.json và trong appspec.yaml đều dùng đúng chuỗi IMAGE1_NAME như cấu hình action ECS_BlueGreen_Deploy.
Lỗi: Deploy stage bị treo ở trạng thái InProgress quá lâu rồi rollback.
Nguyên nhân: Target Group Green không pass health check (thường do Security Group hoặc port container sai).
Giải pháp: Kiểm tra log ECS Task mới trên CloudWatch, đối chiếu ContainerPort trong appspec.yaml có khớp port ứng dụng lắng nghe (3000) không.

Dọn dẹp resource

Bắt buộc thực hiện: Resource CI/CD (CodePipeline, CodeBuild, CodeDeploy, S3 artifact bucket, SNS Topic) do chính bạn tự chạy lệnh xoá — không nhờ Claude Code chạy giúp. Lệnh dưới đây chỉ xoá resource của module cicd, hạ tầng ECS/ECR/RDS/ALB tạo ở Chapter 5 vẫn giữ nguyên (nếu muốn xoá toàn bộ, dùng terraform destroy không kèm -target sau khi hoàn tất toàn bộ khoá học). 
cd D:\lab-expense-management\infra\terraform\environments\dev

  --connection-arn <connection-arn-đã-confirm-ở-Phần-1> `
