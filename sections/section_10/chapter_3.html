10. Phát triển phần mềm với Spec-Kit Framework / Lab - Khởi tạo project mới CodeKids Blocks với specify init
Từ chapter này, cả 5 bài lab của Section 10 (Chapter 3-7) sẽ xây dựng một sản phẩm hoàn toàn mới: CodeKids Blocks — website học lập trình dạng kéo thả khối lệnh (drag-and-drop) dành cho học sinh 7-12 tuổi, giúp các em điều khiển một nhân vật vượt mê cung bằng cách ghép các khối lệnh (Đi tới, Rẽ trái, Rẽ phải, Lặp lại...) — tương tự tinh thần của Scratch/Blockly. Đây là project mới hoàn toàn (khác với lab-expense-management ở các section trước), vì mục tiêu của Section 10 là trải nghiệm trọn vẹn quy trình SDD từ con số 0: phân tích yêu cầu → constitution → spec → plan → tasks → implement.

Mục tiêu

  • Cài đặt Python 3.11+, uv và specify CLI (nếu máy chưa có).
  • Khởi tạo project Next.js + TypeScript + Prisma hoàn toàn mới cho CodeKids Blocks.
  • Chạy specify init để thêm bộ khung Spec-Kit vào project vừa tạo.
  • Xác nhận cấu trúc .specify/ và slash command /speckit.* dùng được trong Claude Code.

Khác với các bài lab trước dùng lại lab-expense-management, CodeKids Blocks là project Next.js + Prisma hoàn toàn mới, chạy MySQL cục bộ qua Docker khi phát triển — Chapter 7 sẽ thay database này bằng TiDB Serverless khi triển khai lên Vercel.

Yêu cầu trước khi bắt đầu

  • Node.js 20+ và npm đã cài đặt — kiểm tra bằng node --version.
  • Docker Desktop đã cài đặt và đang chạy (dùng cho MySQL cục bộ khi phát triển).
  • Claude Code CLI đã cài đặt và đăng nhập thành công.
  • Git đã cài đặt — kiểm tra bằng git --version.
  • Python 3.11 trở lên đã cài đặt hoặc sẽ được cài ở Bước 1.
  • Terminal: PowerShell hoặc Windows Terminal. Kết nối Internet ổn định để tải package/template.

Các bước thực hành

Phần 1: Cài đặt Python, uv và specify CLI

  1. Bước 1: Kiểm tra phiên bản Python hiện có

    Spec-Kit yêu cầu Python 3.11 trở lên.

    python --version
Python 3.12.4

    Nếu chưa có Python hoặc phiên bản thấp hơn 3.11, tải bản mới nhất tại python.org/downloads và cài đặt trước khi tiếp tục.

  2. Bước 2: Cài đặt uv (Python package/tool manager) 
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    Mở lại terminal mới để PATH được nạp lại, sau đó kiểm tra uv đã cài thành công.

    uv --version
uv 0.5.11
  3. Bước 3: Cài đặt specify CLI từ repository Spec-Kit 
    uv tool install specify-cli --from git+https://github.com/github/spec-kit.git
    specify --help

Phần 2: Khởi tạo project Next.js + Prisma mới cho CodeKids Blocks

  1. Bước 4: Tạo project Next.js mới

    Chạy tại thư mục cha nơi bạn muốn chứa project (vd D:\).

    cd D:\
npx create-next-app@latest lab-codekids-blocks --typescript --app --eslint --tailwind=false --src-dir=false --import-alias "@/*"
    cd D:\lab-codekids-blocks
  2. Bước 5: Cài Prisma và khởi tạo schema 
    npm install prisma @prisma/client
npx prisma init --datasource-provider mysql

    Lệnh trên tạo thư mục prisma/ với file schema.prisma (provider mysql — tương thích cả MySQL cục bộ lẫn TiDB Serverless dùng ở Chapter 7) và file .env chứa biến DATABASE_URL.

  3. Bước 6: Tạo docker-compose.yml chạy MySQL cục bộ

    Tạo file docker-compose.yml ở thư mục gốc project với nội dung sau.

    services:
  mysql:
    image: mysql:8.0
    container_name: codekids-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: codekids_root
      MYSQL_DATABASE: codekids
      MYSQL_USER: codekids
      MYSQL_PASSWORD: codekids_pass
    ports:
      - "3306:3306"
    volumes:
      - codekids_mysql_data:/var/lib/mysql

volumes:
  codekids_mysql_data:
    docker compose up -d
  4. Bước 7: Cập nhật DATABASE_URL trỏ vào MySQL vừa chạy

    Sửa lại file .env tại thư mục gốc project.

    DATABASE_URL="mysql://codekids:codekids_pass@localhost:3306/codekids"

Phần 3: Khởi tạo Spec-Kit vào project vừa tạo

  1. Bước 8: Chạy specify init để khởi tạo Spec-Kit vào project hiện tại 
    specify init --here --ai claude
    Lưu ý: Tên flag chính xác (--here, --ai...) có thể thay đổi theo phiên bản Spec-Kit mới nhất. Nếu lệnh trên báo lỗi flag không hợp lệ, chạy specify init --help để xem đúng tên tuỳ chọn hiện hành.
  2. Bước 9: Xác nhận các bước khởi tạo (nếu CLI hỏi)

    specify init có thể hỏi xác nhận trước khi ghi file vào project đã có sẵn Next.js/Prisma. Đọc kỹ và xác nhận đồng ý.

  3. Bước 10: Kiểm tra cấu trúc .specify/ vừa được tạo 
    dir
.specify
app
prisma
docker-compose.yml
package.json
  4. Bước 11: Mở Claude Code và xác nhận slash command /speckit.* xuất hiện 
    claude
    /speckit.

    Danh sách gợi ý hiện ra nên có đủ /speckit.constitution, /speckit.specify, /speckit.plan, /speckit.tasks, /speckit.implement.

✅ Kết quả mong đợi

Project D:\lab-codekids-blocks là một app Next.js + Prisma chạy được (npm run dev mở localhost:3000 ra trang mặc định), có MySQL chạy trong Docker, và có thêm thư mục .specify/. Trong Claude Code, gõ /speckit. hiện ra đủ 5 slash command chính, sẵn sàng cho bài lab phân tích yêu cầu tiếp theo.

Troubleshoot

Lỗi: Terminal báo uv hoặc specify không phải lệnh nhận diện được (not recognized).
Nguyên nhân: PATH chưa được nạp lại sau khi cài — terminal đang mở là session cũ.
Giải pháp: Đóng hẳn terminal đang dùng, mở terminal mới rồi chạy lại lệnh kiểm tra phiên bản.
Lỗi: docker compose up -d báo cổng 3306 đã được dùng.
Nguyên nhân: Đã có MySQL khác (vd container của lab-expense-management) đang chiếm cổng 3306.
Giải pháp: Dừng container cũ (docker compose down ở project cũ) hoặc đổi cổng mapping trong docker-compose.yml của CodeKids Blocks sang cổng khác (vd 3307:3306) và cập nhật lại DATABASE_URL tương ứng.
Lỗi: Trong Claude Code, gõ /speckit. không thấy gợi ý slash command nào.
Nguyên nhân: Claude Code đang chạy phiên mở từ trước khi specify init hoàn tất.
Giải pháp: Thoát phiên Claude Code hiện tại (/exit) và chạy lại claude trong đúng thư mục project.
