10. Phát triển phần mềm với Spec-Kit Framework / Giới thiệu Spec-Kit & cài đặt specify CLI

Giới thiệu

Spec-Kit (github.com/github/spec-kit) là công cụ mã nguồn mở do GitHub phát hành, hiện thực hoá triết lý Spec-Driven Development đã học ở chương trước thành một quy trình cụ thể có thể dùng ngay. Thành phần chính là CLI tên specify — dùng để khởi tạo bộ khung thư mục, template đặc tả, và các slash command /speckit.* tương ứng cho AI coding agent (Claude Code, và một số agent khác). Sau khi cài đặt, học viên chỉ cần gõ slash command ngay trong Claude Code để đi qua từng giai đoạn của SDD, không cần tự tay tạo file hay nhớ cấu trúc đặc tả.

Các tính năng chính

  • CLI specify khởi tạo (init) bộ khung Spec-Kit ngay trong một project — tạo thư mục .specify/ và các file slash command mà Claude Code có thể nhận diện.
  • Hỗ trợ nhiều AI coding agent khác nhau (Claude Code là một trong số đó) — khi khởi tạo có thể chỉ định agent đích để Spec-Kit sinh đúng định dạng slash command phù hợp.
  • Đóng gói sẵn template cho từng giai đoạn SDD (constitution, specify, plan, tasks, implement) — học viên không cần tự thiết kế cấu trúc đặc tả từ đầu.
  • Mã nguồn mở, cập nhật thường xuyên trên GitHub — có thể theo dõi thay đổi, đóng góp, hoặc tuỳ biến template nếu cần.
  • Không phụ thuộc dịch vụ cloud nào — toàn bộ file sinh ra (constitution, spec, plan, tasks) đều là file Markdown lưu ngay trong project, quản lý được bằng Git như code thông thường.

Yêu cầu trước khi cài đặt

Python
Phiên bản 3.11 trở lên — kiểm tra bằng python --version.
Git
Đã cài đặt và có thể gọi từ terminal — kiểm tra bằng git --version.
uv
Python package/tool manager — dùng để cài và chạy specify CLI mà không cần quản lý virtualenv thủ công.
Claude Code
Đã cài đặt và đăng nhập thành công (xem lại Section 2) — nơi các slash command /speckit.* sẽ được sử dụng.

Ví dụ lệnh cài đặt

Cài specify CLI như một tool cố định (khuyến nghị nếu dùng thường xuyên):

uv tool install specify-cli --from git+https://github.com/github/spec-kit.git

Hoặc chạy trực tiếp không cần cài cố định (uv tự tải và chạy trong môi trường tạm):

uvx --from git+https://github.com/github/spec-kit.git specify init <project-name>
Lưu ý: Tham số/flag cụ thể của lệnh specify init (chọn AI agent đích, khởi tạo vào thư mục hiện tại thay vì tạo thư mục mới...) có thể thay đổi giữa các phiên bản Spec-Kit. Luôn chạy specify --help hoặc specify init --help, hoặc tham khảo github.com/github/spec-kit để có danh sách tuỳ chọn đầy đủ và mới nhất trước khi thực hành.

Use Cases

Thêm SDD vào project đã có sẵn

Không cần tạo project mới — Spec-Kit có thể khởi tạo ngay trong một codebase đang chạy để áp dụng SDD cho các tính năng mới.

Chuẩn hoá quy trình làm việc với AI agent

Cùng một bộ slash command, cùng một cấu trúc file — dễ chia sẻ cách làm việc giữa nhiều thành viên trong team.

Theo dõi lịch sử đặc tả qua Git

Vì spec/plan/task đều là file Markdown, mọi thay đổi đặc tả đều có thể xem lại qua git log/git diff như code thông thường.

Thông tin bổ sung

Spec-Kit là project phát triển tích cực — tên lệnh con, cấu trúc thư mục sinh ra, hoặc danh sách agent được hỗ trợ có thể được bổ sung/thay đổi theo thời gian. Chương thực hành tiếp theo (Lab - Cài đặt & khởi tạo project) sẽ hướng dẫn cài đặt từng bước cụ thể trên project lab-expense-management đã tạo ở Section 4.
