10. Phát triển phần mềm với Spec-Kit Framework / Lab - Cài đặt & khởi tạo project với specify init
Bài lab này dùng lại project D:\lab-expense-management đã tạo ở Section 4 (Next.js + Prisma + MySQL). Không tạo project mới — Spec-Kit sẽ được khởi tạo trực tiếp vào project đã tồn tại này, vì đây là áp dụng SDD cho một tính năng mới trên codebase đã có sẵn. Cả 4 bài lab của Section 10 (Chapter 5-8) dùng chung một tính năng duy nhất: xuất báo cáo chi tiêu theo khoảng thời gian dạng PDF/Excel.

Mục tiêu

  • Cài đặt Python 3.11+ (nếu máy chưa có), cài uv và specify CLI.
  • Chạy specify init để khởi tạo Spec-Kit ngay trong project D:\lab-expense-management đã có sẵn.
  • Kiểm tra cấu trúc .specify/ được tạo ra đúng vị trí.
  • Xác nhận các slash command /speckit.* xuất hiện và dùng được trong Claude Code.

Spec-Kit không tạo project mới — chỉ thêm thư mục .specify/ và slash command vào project Next.js đã tồn tại, giữ nguyên toàn bộ code hiện có.

Yêu cầu trước khi bắt đầu

  • Đã hoàn thành Section 4 — project D:\lab-expense-management tồn tại và chạy được (npm run dev).
  • Claude Code CLI đã cài đặt và đăng nhập thành công.
  • Git đã cài đặt — kiểm tra bằng git --version.
  • Python 3.11 trở lên đã cài đặt hoặc sẽ được cài ở Bước 1.
  • Terminal: PowerShell hoặc Windows Terminal.
  • Kết nối Internet ổn định để uv/specify tải package và template từ GitHub.

Các bước thực hành

Phần 1: Cài đặt Python, uv và specify CLI

  1. Bước 1: Kiểm tra phiên bản Python hiện có

    Spec-Kit yêu cầu Python 3.11 trở lên. Kiểm tra trước khi cài thêm.

    python --version
Python 3.12.4

    Nếu chưa có Python hoặc phiên bản thấp hơn 3.11, tải bản mới nhất tại python.org/downloads và cài đặt trước khi tiếp tục.

  2. Bước 2: Cài đặt uv (Python package/tool manager)

    Chạy lệnh cài đặt chính thức của uv cho Windows qua PowerShell.

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    Mở lại terminal mới (để PATH được nạp lại), sau đó kiểm tra uv đã cài thành công.

    uv --version
uv 0.5.11
  3. Bước 3: Cài đặt specify CLI từ repository Spec-Kit

    Dùng uv tool install để cài specify như một CLI cố định, dùng lại được cho các project khác sau này.

    uv tool install specify-cli --from git+https://github.com/github/spec-kit.git

    Kiểm tra CLI đã cài thành công và xem danh sách tuỳ chọn hiện có.

    specify --help

Phần 2: Khởi tạo Spec-Kit vào project lab-expense-management

  1. Bước 4: Vào thư mục project đã có sẵn

    Không tạo thư mục mới — vào đúng project đã tạo ở Section 4.

    cd D:\lab-expense-management
  2. Bước 5: Chạy specify init để khởi tạo Spec-Kit vào project hiện tại

    Chỉ định AI agent đích là Claude Code và khởi tạo ngay trong thư mục hiện tại (không tạo thư mục project mới).

    specify init --here --ai claude
    Lưu ý: Tên flag chính xác (--here, --ai...) có thể thay đổi theo phiên bản Spec-Kit mới nhất. Nếu lệnh trên báo lỗi flag không hợp lệ, chạy specify init --help để xem đúng tên tuỳ chọn hiện hành cho "khởi tạo vào thư mục hiện có" và "chọn AI agent là Claude Code".
  3. Bước 6: Xác nhận các bước khởi tạo (nếu CLI hỏi)

    specify init có thể hỏi xác nhận trước khi ghi file vào project đã có sẵn (để tránh ghi đè file không mong muốn). Đọc kỹ và xác nhận đồng ý.

  4. Bước 7: Kiểm tra cấu trúc .specify/ vừa được tạo

    Xác nhận thư mục .specify/ đã xuất hiện, không ảnh hưởng đến code Next.js hiện có (app/, prisma/, lib/...).

    dir
.specify
app
prisma
lib
docker-compose.yml
package.json
  5. Bước 8: Mở Claude Code và xác nhận slash command /speckit.* xuất hiện

    Khởi động Claude Code trong đúng project vừa khởi tạo, gõ dấu / kèm speckit để xem danh sách slash command khả dụng.

    claude
    /speckit.

    Danh sách gợi ý hiện ra nên có đủ /speckit.constitution, /speckit.specify, /speckit.plan, /speckit.tasks, /speckit.implement.

✅ Kết quả mong đợi

Thư mục D:\lab-expense-management có thêm .specify/ bên cạnh code Next.js hiện có, không file nào của tính năng cũ (CRUD expense, xuất CSV) bị thay đổi. Trong Claude Code, gõ /speckit. hiện ra đủ 5 slash command chính, sẵn sàng dùng cho bài lab tiếp theo.

Troubleshoot

Lỗi: Terminal báo uv hoặc specify không phải lệnh nhận diện được (not recognized).
Nguyên nhân: PATH chưa được nạp lại sau khi cài — terminal đang mở là session cũ trước khi cài đặt.
Giải pháp: Đóng hẳn terminal đang dùng, mở terminal mới rồi chạy lại lệnh kiểm tra phiên bản.
Lỗi: specify init báo lỗi liên quan phiên bản Python quá thấp.
Nguyên nhân: Máy có nhiều phiên bản Python, terminal đang trỏ vào bản cũ hơn 3.11.
Giải pháp: Kiểm tra lại bằng python --version, cài đè bản Python 3.11+ mới hoặc dùng py -3.12 để chỉ định rõ phiên bản khi cần.
Lỗi: Trong Claude Code, gõ /speckit. không thấy gợi ý slash command nào.
Nguyên nhân: Claude Code đang chạy phiên làm việc mở từ trước khi specify init hoàn tất, chưa quét lại slash command mới.
Giải pháp: Thoát phiên Claude Code hiện tại (/exit hoặc Ctrl+C) và chạy lại claude trong đúng thư mục project.
