# Testscript Generator

## Nguyên tắc
- Góc nhìn Tester (black-box): chỉ gọi API qua HTTP, KHÔNG đọc code implementation (route handler, service...).
- Input bắt buộc người dùng cung cấp: 
  - Đường dẫn file test case (`plans/test/*.md`) 
  - base URL + endpoint cần test.
  - API Spect (OpenAPI/Swagger) nếu có, để Claude Code đối chiếu với file test case.

## Quy trình
1. Đọc file test case, map mỗi dòng Test Case (TC) thành một request + assertion (status code, và response body khi test case có nêu).
2. Sinh script chuẩn **Grafana K6**, `VUs = 1` (chưa phải performance test).
3. Trong `setup()`: gọi `POST /api/auth/login` với credential từ biến môi trường (`.env`) để lấy access token; gọi `GET /api/categories?pageSize=200` và `GET /api/accounts?pageSize=100` để lấy sẵn `categoryId`, `accountId` hợp lệ. Token dùng cho mọi request sau.
4. Ghi script ra `test/{domain}/{sub-domain}/testscript.js`.
5. Thêm script chạy tương ứng vào `package.json` (vd `"test:api_transaction_expense": "k6 run test/transaction/expense/testscript.js"`).
6. Giả định server đã deploy sẵn — KHÔNG tự khởi động server trong script.

## Sau khi sinh
In ra bảng tóm tắt: mỗi TC ↔ request ↔ assertion, để Tester đối chiếu nhanh với file test case gốc.

Phần 4: Tham khảo nội dung file test

Nội dung dưới đây là ví dụ tham khảo cho những gì Claude Code nên sinh ra ở Bước 3 (rút gọn, chỉ giữ 2/3 test case để minh hoạ) — dùng để đối chiếu, không cần tự tay chép lại.

tests/expenses.api.test.jsconst { test, before } = require('node:test');
const assert = require('node:assert/strict');

const BASE_URL = 'http://localhost:3000';
let categoryId;

before(async () => {
  const res = await fetch(`${BASE_URL}/api/categories`);
  const categories = await res.json();
  categoryId = categories[0].id;
});

test('tạo khoản chi tiêu hợp lệ (happy path)', async () => {
  const res = await fetch(`${BASE_URL}/api/expenses`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title: 'Ăn trưa', amount: 50000, categoryId, spentAt: new Date().toISOString() })
  });
  assert.ok(res.status === 200 || res.status === 201);
});

test('từ chối khi amount <= 0', async () => {
  const res = await fetch(`${BASE_URL}/api/expenses`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title: 'Test âm', amount: -100, categoryId, spentAt: new Date().toISOString() })
  });
  assert.equal(res.status, 400);
});

// test case 3 (ngày ở tương lai) tương tự, xem file đầy đủ Claude Code sinh ra

Troubleshoot

Lỗi: Claude không gọi Skill testscript-generator, hoặc sinh script không theo chuẩn K6 / thiếu bước login.
Nguyên nhân: Skill chưa được nạp (phiên mở trước khi tạo Skill), hoặc description chưa khớp từ khoá trong prompt.
Giải pháp: Kiểm tra /skills, mở lại phiên; nêu tường minh "dùng skill testscript-generator" ở đầu prompt như Bước 5.
Lỗi: node --test báo không nhận diện được cú pháp hoặc lệnh không tồn tại.
Nguyên nhân: Phiên bản Node.js thấp hơn 18, chưa hỗ trợ đầy đủ built-in test runner và fetch toàn cục.
Giải pháp: Kiểm tra bằng node -v, nâng cấp lên Node.js 18 trở lên nếu cần.
Lỗi: Test case happy path cũng fail vì categoryId/accountId không hợp lệ.
Nguyên nhân: Database chưa có category nào (bảng Category rỗng).
Giải pháp: kết nối với Database tại localhost hoặc TiDB sau đó insert vài data mẫu.
