8. Model Context Protocol (MCP) / Các MCP Server phổ biến (filesystem, Git, database, CodeGraph)

Giới thiệu

Hệ sinh thái MCP Server đang phát triển rất nhanh — có cả Server do Anthropic/nhà cung cấp dịch vụ chính thức duy trì, và rất nhiều Server do cộng đồng tự viết và công bố công khai (thường trên GitHub hoặc các MCP registry). Chương này giới thiệu 4 nhóm MCP Server phổ biến nhất mà học viên nên biết trước khi bắt đầu thực hành ở 2 bài Lab tiếp theo của Section này.

Các tính năng chính

  • Mỗi nhóm MCP Server phục vụ một loại nhu cầu khác nhau — nên chọn đúng nhóm phù hợp với công việc thay vì cố dùng một Server cho mọi việc.
  • Có thể kết nối nhiều MCP Server thuộc nhiều nhóm khác nhau cùng lúc trong một phiên làm việc với Claude Code.
  • Tên gói cụ thể (package npm, repository GitHub) của từng Server thay đổi theo thời gian — nên tra cứu MCP registry/GitHub tại thời điểm học để tìm phiên bản đang được duy trì tốt nhất.

Claude Code có thể kết nối đồng thời nhiều MCP Server thuộc các nhóm khác nhau, mỗi Server phục vụ một mảng khả năng riêng biệt.

📁 Filesystem
Đọc/ghi file

Cho phép Claude đọc/ghi file ngoài phạm vi thư mục project hiện tại — ví dụ đọc tài liệu chung của team, ghi kết quả ra một thư mục chia sẻ. Claude Code mặc định chỉ thao tác trong thư mục project đang mở; MCP Server filesystem mở rộng phạm vi này khi cần, đi kèm rủi ro cần cấp đúng phạm vi thư mục cho phép.

Git
Thao tác Git nâng cao

Cung cấp Tool cho các thao tác Git phức tạp hơn mức Claude Code tự gọi lệnh git thông thường — ví dụ tìm kiếm trong lịch sử commit, phân tích blame theo cấu trúc, quản lý nhiều repository cùng lúc theo chuẩn thống nhất.

Database
MySQL / PostgreSQL

Cho phép Claude Code tự chạy câu lệnh SQL (SELECT, và tuỳ quyền cấp có thể cả INSERT/UPDATE) trên database thật — dùng phổ biến nhất để tự kiểm chứng một thao tác ghi dữ liệu đã đúng, thay vì phải tin vào báo cáo của Claude hoặc tự mở công cụ quản trị DB kiểm tra tay. Thực hành ở Lab 2 (Chapter 6).

🔍 CodeGraph
Phân tích quan hệ code

Nhóm MCP Server phân tích call graph (hàm nào gọi hàm nào) và dependency graph (module nào phụ thuộc module nào) giữa các file trong một codebase. Giúp Claude Code hiểu đúng phạm vi ảnh hưởng trước khi sửa một tính năng trong project lớn. Thực hành ở Lab 1 (Chapter 5).

Use Cases

Đọc tài liệu ngoài project

MCP Server filesystem giúp Claude Code đọc thêm tài liệu đặc tả nằm ở thư mục dùng chung của team, không cần copy vào trong project.

Kiểm chứng dữ liệu sau thao tác ghi

MCP Server database giúp Claude tự chạy SELECT xác nhận một khoản ghi dữ liệu (tạo/sửa) đã đúng như yêu cầu.

Sửa tính năng an toàn hơn trong codebase lớn

MCP Server CodeGraph giúp xác định trước những file/route bị ảnh hưởng khi sửa một hàm dùng chung, giảm rủi ro sửa sai chỗ hoặc bỏ sót nơi cần cập nhật.

Thông tin bổ sung

Lưu ý về tên gọi "CodeGraph": Khác với filesystem, Git hay database — vốn là loại hệ thống rõ ràng — "CodeGraph" trong khoá học này là tên gọi minh hoạ cho một nhóm/loại MCP Server chuyên phân tích quan hệ code (call graph, dependency graph), không phải tên một sản phẩm/package cố định duy nhất. Tại thời điểm thực hành, học viên nên tự tìm trên MCP registry hoặc GitHub với từ khoá như "mcp server code graph", "mcp server dependency analysis", chọn Server phù hợp với ngôn ngữ/framework của project đang dùng (ví dụ TypeScript/Next.js cho project mẫu ở Lab 1 của Section này).

Tương tự, với nhóm database, không phải mọi MCP Server MySQL/PostgreSQL đều hỗ trợ đầy đủ các thao tác giống nhau — một số chỉ hỗ trợ đọc (SELECT), một số hỗ trợ cả ghi. Luôn đọc kỹ tài liệu của Server trước khi cấu hình, và áp dụng nguyên tắc least privilege đã học ở Chapter 3 khi cấp quyền kết nối database cho MCP Server.
