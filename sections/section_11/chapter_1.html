11. Tổng kết & Định hướng nâng cao / Tổng hợp công cụ đã học & khi nào dùng cái gì

Giới thiệu

Xuyên suốt 10 Section vừa qua, chúng ta đã đi từ giao diện chat cơ bản đến những cơ chế mở rộng khả năng của Claude ở mức sâu hơn: Skill, Sub-agent, MCP, Hook, và Spec-Kit. Mỗi công cụ giải quyết một loại vấn đề khác nhau, và trong công việc thực tế rất hiếm khi chỉ dùng đúng một công cụ — thường là kết hợp vài công cụ với nhau tuỳ theo tình huống. Chương này hệ thống hoá lại toàn bộ các công cụ đã học và cung cấp một sơ đồ quyết định nhanh để trả lời câu hỏi thường gặp nhất: "Với việc này, tôi nên dùng cái gì?"

Các công cụ đã học trong khoá

💬

Claude Desktop App / Claude.ai

Section 2 — Giao diện chat trực tiếp, có Projects và Artifacts. Phù hợp hỏi đáp, soạn thảo nhanh, không cần thao tác trực tiếp trên file/project.

⌨️

Claude Code

Section 2, 4–7 — Trợ lý dòng lệnh (CLI), đọc/sửa file trực tiếp, chạy lệnh, giữ ngữ cảnh project qua CLAUDE.md.

🧩

Claude Skill

Section 3 — Đóng gói một quy trình/hướng dẫn hay lặp lại thành tài nguyên tái sử dụng, Claude tự nhận diện khi cần dùng.

🤖

Sub-agent

Section 3 — Tác vụ chuyên biệt hoá, có phạm vi tool/system prompt riêng, chạy trong context tách biệt với Agent chính.

🔌

MCP

Section 8 — Chuẩn giao tiếp giúp Claude Code kết nối với hệ thống bên ngoài phạm vi file local: codebase (CodeGraph), database (MySQL)...

⚙️

Hook

Section 9 — Chèn shell command vào vòng đời làm việc của Claude Code, chạy độc lập với model theo event + matcher cố định.

📜

Spec-Kit

Section 10 — Framework Spec-Driven Development, kết hợp Claude Code để phát triển tính năng có kiểm soát từ đặc tả đến code.

Use Cases

Developer (Section 4, 8)

Dùng Claude Code làm công cụ chính, kết hợp MCP CodeGraph để hiểu quan hệ giữa các module trước khi sửa tính năng lớn.

DevOps/Cloud Engineer (Section 5, 9)

Dùng Claude Code sinh/review Terraform, kết hợp Hook để tự động chạy kiểm tra an toàn sau mỗi lần chỉnh sửa hạ tầng.

Tester/QA (Section 6, 3)

Dùng Claude sinh test case từ requirement, đóng gói thành Skill để tái sử dụng cho các requirement tương tự về sau.

Project Manager (Section 7)

Dùng Claude Desktop App/Claude Projects để soạn tài liệu, tóm tắt họp, giữ ngữ cảnh dự án xuyên suốt nhiều buổi làm việc.

Thông tin bổ sung

Sơ đồ và bảng quyết định ở trên chỉ mang tính gợi ý để chọn nhanh — ranh giới giữa các công cụ không tuyệt đối, và phần lớn công việc thực tế sẽ cần kết hợp nhiều hơn một công cụ cùng lúc (ví dụ Claude Code làm nền, MCP để kết nối dữ liệu, Hook để tự động hoá phần phụ trợ). Bảng này sẽ được dùng lại ở Chapter 3 khi thực hiện bài tập tổng hợp cuối khoá — hãy dùng nó như điểm khởi đầu để tự quyết định công cụ phù hợp cho bài toán của riêng bạn.
