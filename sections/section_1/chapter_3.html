1. Giới thiệu khóa học / Yêu cầu đầu vào & Lưu ý trong quá trình học

Giới thiệu

Khóa học được thiết kế cho người mới bắt đầu, không yêu cầu kiến thức lập trình chuyên sâu. Tuy nhiên, để việc thực hành các bài lab diễn ra thuận lợi, bạn nên chuẩn bị trước một số công cụ và tài khoản cần thiết.

Yêu cầu đầu vào

Kiến thức nền tảng

  • Không yêu cầu biết lập trình chuyên sâu — phù hợp với mọi background, kể cả người không thuộc ngành IT.
  • Biết sử dụng cơ bản VS Code (mở project, dùng terminal tích hợp) là một lợi thế.
  • Biết thao tác Git cơ bản (clone, commit, push, pull) là một lợi thế, đặc biệt khi thực hành các lab tích hợp Git (CICD, code review).
  • Biết một trong các ngôn ngữ lập trình (Python, JavaScript, Java...) và có kiến thức cơ bản về Database (SQL) sẽ giúp bạn thực hành các lab nhanh và hiểu sâu hơn.

Tài khoản cần chuẩn bị

  • Tài khoản GitHub (miễn phí) — dùng để lưu trữ code trong các bài lab thực hành.
  • Tài khoản Claude (Personal, Team hoặc Enterprise tùy nhu cầu) — dùng cho toàn bộ các bài thực hành với Claude Desktop App và Claude Code trong khóa học.

Thiết bị & kết nối

  • Laptop/máy tính cá nhân (Windows, macOS hoặc Linux đều được), đủ cấu hình để chạy VS Code và Docker (một số lab ở Section 4 sử dụng Docker cho database).
  • Kết nối Internet ổn định xuyên suốt quá trình học — Claude Desktop App và Claude Code đều cần kết nối mạng để hoạt động.

Lưu ý trong quá trình học

Chi phí (Cost): Claude tính phí theo lượng token sử dụng (Personal/Team theo gói subscription, API theo usage). Luôn theo dõi mức sử dụng, chọn model phù hợp với độ khó tác vụ (Haiku cho tác vụ đơn giản, Sonnet cho công việc hằng ngày, Opus cho tác vụ phức tạp) để tránh phát sinh chi phí không cần thiết.
Bảo mật (Security): Tuyệt đối không commit các thông tin nhạy cảm (API key, mật khẩu, secret, file .env...) lên GitHub, kể cả private repository. Việc lộ thông tin nhạy cảm có thể dẫn đến các security incident nghiêm trọng. Luôn thêm các file này vào .gitignore trước khi commit.
Backup: Luôn backup code sau mỗi phiên làm việc với Claude Code (commit & push lên GitHub) và backup database khi cần thiết. Claude cũng như các công cụ AI nói chung có khả năng gặp sai sót trong quá trình thực thi yêu cầu (vd xóa nhầm file, edit làm hỏng các source code gốc), bạn cần backup code thường xuyên sau mỗi phiên làm việc hoặc hoàn thành một chức năng để có thể rollback lại nếu gặp sự cố.

Thông tin bổ sung

Nếu bạn chưa có kinh nghiệm với VS Code, Git hoặc lập trình, vẫn có thể theo học bình thường — các bài lab đều hướng dẫn command chi tiết, copy-paste được ngay. Những kiến thức nền tảng nêu trên chỉ giúp bạn thực hành nhanh và hiểu sâu hơn, không phải điều kiện bắt buộc. Việc chuẩn bị đầy đủ tài khoản GitHub và Claude trước khi vào Section 2 sẽ giúp bạn không bị gián đoạn trong quá trình thực hành.
