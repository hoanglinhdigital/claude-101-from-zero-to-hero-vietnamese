2. Làm quen với Claude / Lab: Thao tác cơ bản với Claude trên máy local

Mục tiêu

  • Sử dụng thành thạo Claude Desktop App để hỏi đáp, duy trì ngữ cảnh trong một cuộc trò chuyện.
  • Đính kèm và phân tích một tài liệu thực tế (PDF/Word/txt), yêu cầu Claude tóm tắt và trích xuất thông tin chính.
  • Dùng Claude Desktop App để sinh code một game hoàn chỉnh (Snake Game) bằng HTML/CSS/JS thuần và xem trực tiếp kết quả qua tính năng Artifacts.
  • Biết cách lưu lại kết quả (code, bản tóm tắt) ra file trên máy local để sử dụng sau.

Claude Desktop App là điểm chạm duy nhất cho cả ba tác vụ: hỏi đáp, phân tích tài liệu và sinh code — mọi yêu cầu đều được gửi tới Anthropic API để xử lý, kết quả code có thể được xem trực tiếp qua Artifact và lưu ra file local.

Yêu cầu trước khi bắt đầu

  • Claude Desktop App đã được cài đặt và đăng nhập thành công (xem lại Lab ở Section 2, Chapter 1).
  • Một tài liệu mẫu bất kỳ để thực hành phân tích — có thể dùng file PDF/Word/txt sẵn có trên máy (báo cáo, hợp đồng, bài viết...).
  • Kết nối Internet ổn định trong suốt quá trình thực hành.
  • Một thư mục trên máy local để lưu lại code game sau khi hoàn thành, ví dụ D:\lab-claude-desktop\.

Các bước thực hành

Phần 1: Hỏi đáp cơ bản với Claude Desktop App

  1. Bước 1: Tạo cuộc trò chuyện mới

    Mở Claude Desktop App, chọn New chat ở góc trên bên trái để bắt đầu một cuộc trò chuyện trống.

  2. Bước 2: Đặt câu hỏi đơn giản

    Nhập một câu hỏi bất kỳ để làm quen với giao diện chat, ví dụ nhờ Claude giải thích một khái niệm.

    Giải thích ngắn gọn sự khác biệt giữa AI, Machine Learning và Large Language Model (LLM) cho người mới bắt đầu, dùng ví dụ dễ hiểu.
  3. Bước 3: Hỏi tiếp theo (follow-up) để kiểm tra ngữ cảnh

    Trong cùng cuộc trò chuyện, đặt câu hỏi tiếp nối câu trả lời trước — Claude sẽ hiểu được ngữ cảnh mà không cần lặp lại thông tin.

    Từ câu trả lời trên, cho tôi 3 ví dụ thực tế về việc ứng dụng LLM trong công việc của một Developer.
  4. Bước 4: Thử chuyển đổi model

    Nhấn vào tên model ở phía trên khung chat (ví dụ Sonnet), chọn một model khác (Haiku hoặc Opus) và gửi lại một câu hỏi tương tự để so sánh tốc độ và chất lượng câu trả lời.

Phần 2: Phân tích tài liệu & tóm tắt nội dung

  1. Bước 1: Tạo cuộc trò chuyện mới cho tác vụ tài liệu

    Chọn New chat để bắt đầu cuộc trò chuyện riêng cho việc phân tích tài liệu, tránh lẫn ngữ cảnh với phần hỏi đáp ở trên.

  2. Bước 2: Đính kèm tài liệu

    Nhấn vào icon đính kèm (📎) ở khung nhập chat, chọn file tài liệu mẫu đã chuẩn bị (PDF/Word/txt) từ máy local.

    Claude Desktop App hỗ trợ nhiều định dạng phổ biến: PDF, DOCX, TXT, CSV, hình ảnh (PNG/JPG)... Với file PDF scan (dạng ảnh), Claude vẫn có thể đọc được nội dung nhờ khả năng xử lý hình ảnh.
  3. Bước 3: Yêu cầu tóm tắt nội dung chính

    Sau khi file đã được đính kèm, gửi yêu cầu tóm tắt.

    Đọc tài liệu vừa đính kèm và tóm tắt nội dung chính trong 5-7 câu, tập trung vào các ý quan trọng nhất.
  4. Bước 4: Trích xuất thông tin cụ thể

    Tiếp tục hỏi để trích xuất các thông tin có cấu trúc rõ ràng hơn từ tài liệu, ví dụ danh sách ý chính hoặc các mốc thời gian/số liệu quan trọng.

    Liệt kê dưới dạng bullet point các số liệu, ngày tháng hoặc con số quan trọng được nhắc đến trong tài liệu này.

Phần 3: Viết Game Rắn săn mồi (Snake Game) bằng HTML/CSS/JS

  1. Bước 1: Tạo cuộc trò chuyện mới và yêu cầu viết game

    Chọn New chat, sau đó gửi yêu cầu viết game Snake hoàn chỉnh, gộp toàn bộ trong một file HTML duy nhất.

    Viết cho tôi game Rắn săn mồi (Snake game) hoàn chỉnh bằng HTML, CSS và JavaScript thuần (không dùng thư viện ngoài), gộp tất cả trong một file HTML duy nhất. Yêu cầu:
- Điều khiển rắn bằng phím mũi tên (arrow keys).
- Hiển thị điểm số hiện tại.
- Khi rắn ăn mồi thì dài ra và điểm số tăng lên.
- Khi rắn tự đâm vào thân hoặc đâm tường thì hiện thông báo Game Over và nút Chơi lại.
  2. Bước 2: Xem preview trực tiếp qua Artifact

    Claude sẽ trả về code và tự động mở khung Artifact bên phải cửa sổ chat, hiển thị bản preview chạy được ngay của game — không cần copy code ra ngoài để test.

  3. Bước 3: Chơi thử ngay trong Artifact

    Nhấn vào khung Artifact để focus, dùng phím mũi tên điều khiển rắn di chuyển và kiểm tra các tính năng: ăn mồi tăng điểm, game over khi va chạm.

  4. Bước 4: Yêu cầu chỉnh sửa, bổ sung tính năng

    Tiếp tục hội thoại trong cùng chat để yêu cầu Claude tinh chỉnh game — Artifact sẽ tự động cập nhật bản preview mới sau mỗi lần chỉnh sửa.

    Chỉnh sửa game hiện tại: tăng dần tốc độ di chuyển của rắn mỗi khi ăn được 5 mồi, và đổi màu nền game sang tối (dark mode).
  5. Bước 5: Lưu code ra file trên máy local

    Ở góc trên khung Artifact, chọn icon tải xuống (Download) để lưu file, hoặc chọn Copy code rồi dán vào một file mới trong thư mục đã chuẩn bị.

    Đặt tên file là game.html, lưu vào thư mục D:\lab-claude-desktop\. Sau khi lưu, có thể mở trực tiếp file này bằng trình duyệt (double-click) để chơi offline, không cần Claude Desktop App.

Troubleshoot

Lỗi: Không đính kèm được file tài liệu vào chat.
Nguyên nhân: File vượt quá giới hạn kích thước cho phép, hoặc định dạng không được hỗ trợ.
Giải pháp: Kiểm tra dung lượng file (thường giới hạn vài chục MB tuỳ gói cước), thử chuyển sang định dạng phổ biến hơn (PDF, DOCX, TXT) hoặc chia nhỏ tài liệu nếu quá dài.
Lỗi: Artifact không hiển thị preview hoặc hiển thị màn hình trắng.
Nguyên nhân: Code JavaScript bị lỗi cú pháp, hoặc Claude chưa nhận diện được yêu cầu tạo Artifact.
Giải pháp: Yêu cầu Claude kiểm tra và sửa lỗi trong đoạn code đã sinh (ví dụ: "Artifact đang bị màn hình trắng, hãy kiểm tra lại lỗi trong code và sửa"), Claude sẽ tự rà soát và cập nhật lại.
Lỗi: Claude trả lời chậm hoặc bị ngắt giữa câu trả lời dài.
Nguyên nhân: Kết nối Internet không ổn định, hoặc hệ thống Anthropic đang tải cao.
Giải pháp: Kiểm tra lại kết nối mạng, thử gửi lại yêu cầu (resend), hoặc chia nhỏ yêu cầu phức tạp thành nhiều bước nhỏ hơn.
