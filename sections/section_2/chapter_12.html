2. Làm quen với Claude / Lab: Claude Code qua CLI

Mục tiêu

  • Biết cách khởi động Claude Code trong một project cụ thể thông qua terminal.
  • Phân biệt được 4 chế độ tương tác: Manual, Plan mode, Accept Edits mode và Auto — biết khi nào nên dùng chế độ nào.
  • Nắm được các slash command thường dùng nhất và công dụng của từng lệnh.
  • Thực hành dùng Claude Code khởi tạo một project Next.js mới và tự sinh file CLAUDE.md chứa thông tin cơ bản của project.

Yêu cầu trước khi bắt đầu

  • Claude Code CLI đã được cài đặt và đăng nhập thành công (xem lại Lab ở Section 2, Chapter 1).
  • Node.js phiên bản 18 trở lên đã được cài đặt trên máy — cần thiết để khởi tạo project Next.js.
  • Terminal: PowerShell/Windows Terminal/Git Bash
  • Kết nối Internet ổn định trong suốt quá trình thực hành.

Các bước thực hành

Phần 1: Khởi động Claude Code

  1. Bước 1: Tạo thư mục project và di chuyển vào đó

    Claude Code luôn chạy trong ngữ cảnh của một thư mục cụ thể — tạo thư mục mới cho project sẽ thực hành trong lab này.

    
#Tạo thư mục mới cho project lab
mkdir D:\lab-claude-code-cli
#Di chuyển vào thư mục vừa tạo
cd D:\lab-claude-code-cli
#Mở thư mục bằng Visual Studio Code bằng lệnh:
code .
  2. Bước 2: Khởi động Claude Code

    Chạy lệnh claude ngay trong thư mục vừa tạo để bắt đầu phiên làm việc tương tác (interactive session).

    
#Khởi động Terminal bằng phím tắt: Ctrl+` (dấu backtick) hoặc mở PowerShell/Gitbash Terminal mới, sau đó gõ lệnh:
claude
  3. Bước 3: Xác nhận tin tưởng thư mục (Trust folder)

    Ở lần chạy đầu tiên trong một thư mục mới, Claude Code sẽ hỏi có tin tưởng (trust) thư mục này để cho phép đọc/ghi file hay không — chọn Yes, proceed để tiếp tục.

  4. Bước 4: Kiểm tra phiên làm việc đã sẵn sàng

    Sau khi vào phiên tương tác, khung nhập lệnh (prompt box) sẽ hiển thị ở cuối terminal — đây là nơi gõ yêu cầu bằng ngôn ngữ tự nhiên cho Claude Code.

Phần 2: Các chế độ tương tác (Permission Modes)

Claude Code kiểm soát mức độ "hỏi trước khi làm" thông qua Permission Mode (chế độ quyền hạn). Trong phiên làm việc, nhấn Shift+Tab để chuyển đổi qua lại giữa các chế độ cơ bản (Manual → Accept Edits → Plan). Chế độ đang chọn được hiển thị ngay phía dưới khung nhập lệnh, ví dụ ⏸ manual mode on, ⏵⏵ accept edits on hoặc ⏸ plan mode on.

Chế độMô tảKhi nào nên dùng
Manual mode
(mặc định, tên cấu hình default)		 Claude Code chỉ tự động thực hiện các thao tác đọc (đọc file, tìm kiếm...); mọi thay đổi file hoặc lệnh có ảnh hưởng đều cần xác nhận (permission prompt) từng bước. Mới làm quen Claude Code, hoặc đang thao tác trên codebase/dữ liệu nhạy cảm cần kiểm soát chặt.
Plan mode Claude Code chỉ đọc code, phân tích và đề xuất kế hoạch thực hiện — chưa ghi thay đổi nào lên file. Sau khi trình bày kế hoạch, học viên chọn duyệt (approve) và chỉ định chế độ sẽ chuyển sang để Claude bắt đầu thực thi. Tác vụ phức tạp, ảnh hưởng nhiều file, hoặc khi mới làm quen với một codebase — cần xem trước Claude sẽ làm gì trước khi cho phép sửa.
Accept Edits mode
(cấu hình acceptEdits)		 Claude Code tự động sửa/tạo file và chạy một số lệnh filesystem thông dụng (mkdir, mv, cp...) mà không hỏi lại; các lệnh khác vẫn cần xác nhận. Đang review thay đổi trực tiếp trong editor hoặc bằng git diff sau khi Claude hoàn tất, muốn giảm số lần bị hỏi xác nhận cho các thao tác file quen thuộc.
Auto mode
(cấu hình auto, tính năng mới)		 Gần như không hỏi xác nhận — một model phân loại (classifier) riêng sẽ tự động rà soát từng hành động trước khi thực thi và chặn lại các thao tác rủi ro cao (xoá dữ liệu vĩnh viễn, force push, deploy production...). Tác vụ dài, lặp lại nhiều bước, muốn giảm tối đa số lần bị gián đoạn — cần có gói cước phù hợp và model hỗ trợ (xem thêm trong tài liệu chính thức).
Ngoài 4 chế độ trên, Claude Code còn có Don't Ask mode (chỉ chạy các tool đã được duyệt sẵn — dùng cho CI/CD) và Bypass Permissions mode (bỏ qua toàn bộ kiểm tra quyền hạn — chỉ nên dùng trong container/VM cô lập, không có kết nối ra ngoài). Hai chế độ này nằm ngoài phạm vi của bài Lab này.
Lưu ý an toàn: Dù ở chế độ nào (trừ Bypass Permissions), Claude Code vẫn chặn ghi vào một số đường dẫn nhạy cảm (.git, .claude, file cấu hình shell...) và luôn hỏi xác nhận riêng cho các lệnh nguy hiểm như xoá toàn bộ ổ đĩa (rm -rf /). Không nên dùng Auto mode hoặc Bypass Permissions cho các tác vụ chưa từng thử qua ở Accept Edits mode.

Phần 3: Slash Commands thường dùng

Slash command là các lệnh đặc biệt bắt đầu bằng dấu /, gõ trực tiếp trong khung nhập lệnh của Claude Code để thực hiện các tác vụ quản lý phiên làm việc (khác với việc mô tả yêu cầu code bằng ngôn ngữ tự nhiên).

Slash CommandÝ nghĩaCông dụng
/helpTrợ giúpHiển thị danh sách toàn bộ slash command và cách sử dụng cơ bản.
/initKhởi tạo cấu hình projectYêu cầu Claude Code quét project và tự sinh file CLAUDE.md mẫu dựa trên cấu trúc thực tế.
/clearXoá hội thoạiBắt đầu một phiên hội thoại mới, xoá toàn bộ lịch sử chat hiện tại (không ảnh hưởng file đã thay đổi).
/contextXem context windowHiển thị chi tiết context window hiện tại đang được dùng bởi phần nào (system prompt, file đã đọc, lịch sử chat...), giúp biết khi nào nên /compact hoặc /clear.
/compactRút gọn ngữ cảnhTóm tắt lại lịch sử hội thoại dài để giảm số token phải gửi lại, giữ được ngữ cảnh quan trọng.
/resumeTiếp tục phiên cũMở lại một phiên làm việc đã lưu trước đó để tiếp tục thay vì bắt đầu lại từ đầu.
/rewindQuay lại checkpointXem lại lịch sử các checkpoint của hội thoại/code, cho phép khôi phục lại trạng thái trước đó (tin nhắn và/hoặc file) khi cần hoàn tác một bước đi sai hướng.
/modelChọn modelXem hoặc đổi model đang sử dụng cho phiên làm việc (Haiku/Sonnet/Opus).
/statusTrạng tháiKiểm tra tài khoản đang đăng nhập, gói cước và thông tin phiên làm việc hiện tại.
/costChi phíXem ước tính số token/chi phí đã sử dụng trong phiên làm việc hiện tại.
/permissionsQuản lý quyềnXem và chỉnh sửa danh sách quyền (tool nào được tự động cho phép, tool nào cần hỏi lại).
/agentsQuản lý Sub-agentXem, tạo hoặc chỉnh sửa các Sub-agent chuyên biệt (sẽ học chi tiết ở Section 3).
/mcpQuản lý MCP ServerXem danh sách MCP Server đã cấu hình và trạng thái kết nối (sẽ học chi tiết ở Section 8).
/doctorKiểm tra hệ thốngChẩn đoán các vấn đề cấu hình/cài đặt của Claude Code trên máy hiện tại.
/login / /logoutĐăng nhập / đăng xuấtChuyển đổi hoặc đăng xuất tài khoản Anthropic đang dùng cho Claude Code.

Phần 4: Thực hành khởi tạo project Next.js & tạo file CLAUDE.md

  1. Bước 1: Yêu cầu khởi tạo project Next.js

    Trong khung nhập lệnh Claude Code (đang ở Accept Edits mode hoặc Plan mode), gõ yêu cầu khởi tạo project.

    Khởi tạo một project Next.js mới trong thư mục hiện tại, dùng TypeScript, Tailwind CSS và App Router. Sau khi tạo xong, chạy thử để đảm bảo project build không lỗi.
  2. Bước 2: Duyệt kế hoạch (nếu đang ở Plan mode)

    Nếu đang ở Plan mode, Claude Code sẽ hiển thị các bước dự kiến thực hiện (chạy create-next-app, cấu hình các option...) — đọc qua kế hoạch rồi chọn Approve/Yes để Claude Code bắt đầu thực thi.

  3. Bước 3: Xác nhận các thay đổi được đề xuất

    Ở Accept Edits mode, Claude Code sẽ hỏi xác nhận trước khi chạy lệnh khởi tạo project — chọn Yes để tiếp tục cho từng bước.

  4. Bước 4: Kiểm tra kết quả project vừa tạo

    Sau khi hoàn tất, kiểm tra cấu trúc thư mục vừa được sinh ra để xác nhận project đã khởi tạo đúng.

    dir
app
package.json
tailwind.config.ts
tsconfig.json
  5. Bước 5: Yêu cầu tạo file CLAUDE.md

    Vẫn trong phiên làm việc hiện tại (đã có ngữ cảnh về project vừa tạo), yêu cầu Claude Code sinh file CLAUDE.md — có thể dùng slash command /init hoặc mô tả trực tiếp bằng ngôn ngữ tự nhiên.

    /init

    Hoặc mô tả cụ thể hơn nếu muốn kiểm soát nội dung file:

    Tạo file CLAUDE.md cho project này, bao gồm: mô tả ngắn về project (Next.js + TypeScript + Tailwind CSS), cấu trúc thư mục chính, các lệnh thường dùng (dev, build, lint), và quy ước code cơ bản (dùng App Router, không dùng CSS module).
  6. Bước 6: Kiểm tra nội dung file CLAUDE.md

    Mở file CLAUDE.md vừa được tạo ở thư mục gốc project để xác nhận nội dung đầy đủ, đúng với thông tin thực tế của project.

    notepad CLAUDE.md
  7. Bước 7: Chạy thử project

    Yêu cầu Claude Code chạy dev server để kiểm tra project hoạt động đúng, hoặc tự chạy lệnh trực tiếp trong terminal.

    npm run dev

    Mở trình duyệt tại http://localhost:3000 để xác nhận trang mặc định của Next.js hiển thị thành công.

Troubleshoot

Lỗi: Claude Code báo không thể ghi file hoặc chạy lệnh trong thư mục hiện tại.
Nguyên nhân: Thư mục chưa được xác nhận tin tưởng (trust), hoặc đang ở Plan mode nên chưa được phép ghi thay đổi.
Giải pháp: Kiểm tra lại prompt xác nhận trust folder ở lần chạy đầu, hoặc chuyển sang Accept Edits mode (Shift+Tab) rồi duyệt lại kế hoạch.
Lỗi: Lệnh khởi tạo Next.js bị treo, không thấy phản hồi.
Nguyên nhân: create-next-app đang chờ nhập tương tác (interactive prompt) mà Claude Code chưa xử lý được, hoặc kết nối mạng chậm khi tải package.
Giải pháp: Yêu cầu Claude Code chạy create-next-app kèm đầy đủ flag (vd --ts --tailwind --app --yes) để tránh câu hỏi tương tác; kiểm tra lại kết nối Internet.
Lỗi: File CLAUDE.md sinh ra quá chung, không phản ánh đúng project.
Nguyên nhân: Yêu cầu ban đầu chưa nêu rõ những thông tin cần có trong file.
Giải pháp: Yêu cầu Claude Code chỉnh sửa bổ sung từng phần cụ thể (vd "thêm phần quy ước đặt tên component"), hoặc tham khảo cấu trúc CLAUDE.md mẫu sẽ học kỹ hơn ở bài Lab cuối Section này.
