2. Làm quen với Claude / Lab: Cài đặt Claude Desktop & Claude Code (Windows)

Mục tiêu

  • Cài đặt thành công Claude Desktop App trên Windows và đăng nhập bằng tài khoản Anthropic.
  • Cài đặt thành công Claude Code (CLI) trên Windows thông qua npm.
  • Đăng nhập Claude Code bằng tài khoản Anthropic và xác nhận trạng thái đăng nhập.
  • Biết cách xử lý các lỗi thường gặp khi cài đặt và đăng nhập trên Windows.

Cả Claude Desktop App và Claude Code đều xác thực qua trình duyệt (OAuth) với tài khoản Anthropic — sau khi đăng nhập, session token được lưu cục bộ trên máy để dùng cho các lần sau.

Yêu cầu trước khi bắt đầu

  • Windows 10 hoặc Windows 11 (64-bit).
  • Tài khoản Anthropic (Claude.ai) đã tạo ở Section 1 — dùng để đăng nhập cả Claude Desktop App và Claude Code.
  • Node.js phiên bản 18 trở lên — cần thiết để cài đặt Claude Code CLI qua npm.
  • Kết nối Internet ổn định trong suốt quá trình cài đặt và đăng nhập.
  • Terminal: PowerShell hoặc Windows Terminal (khuyến nghị Windows Terminal).

Các bước thực hành

  1. Bước 1: Tải Claude Desktop App

    Truy cập trang tải Claude Desktop App và chọn phiên bản Windows.

    Link tải: https://claude.ai/download — chọn nút Download for Windows để tải file cài đặt Claude-Setup-x64.exe.
  2. Bước 2: Cài đặt Claude Desktop App

    Chạy file cài đặt vừa tải và làm theo hướng dẫn trên màn hình. Ứng dụng sẽ tự khởi động sau khi cài xong.

    .\Claude-Setup-x64.exe
  3. Bước 3: Đăng nhập Claude Desktop App bằng tài khoản Anthropic

    Khi ứng dụng mở lên, chọn Log in, nhập email tài khoản Anthropic (hoặc chọn Continue with Google), sau đó xác nhận mã OTP hoặc magic link được gửi vào email.

  4. Bước 4: Kiểm tra Node.js (yêu cầu cho Claude Code)

    Mở PowerShell và kiểm tra phiên bản Node.js đã cài đặt. Nếu chưa có hoặc phiên bản dưới 18, cài đặt bản LTS mới nhất bằng winget.

    node -v
v20.14.0
npm -v
10.7.0

    Nếu chưa cài Node.js:

    winget install OpenJS.NodeJS.LTS
  5. Bước 5: Cài đặt Claude Code CLI

    Cài đặt Claude Code trên toàn hệ thống (global) thông qua npm.

    npm install -g @anthropic-ai/claude-code
  6. Bước 6: Kiểm tra Claude Code đã cài đặt thành công

    Mở lại (hoặc mở mới) PowerShell rồi kiểm tra phiên bản Claude Code.

    claude --version
1.x.x (Claude Code)
  7. Bước 7: Đăng nhập Claude Code bằng tài khoản Anthropic

    Chạy lệnh claude để khởi động Claude Code, sau đó chọn phương thức đăng nhập bằng tài khoản Anthropic (Claude subscription) hoặc API key (Anthropic Console).

    claude

    Trong màn hình Claude Code, chọn Log in with Anthropic Console/Claude account. Trình duyệt sẽ tự mở trang đăng nhập — hoàn tất OAuth trên trình duyệt rồi quay lại terminal.

  8. Bước 8: Xác nhận đăng nhập thành công

    Sau khi đăng nhập, gõ lệnh /status trong Claude Code để kiểm tra tài khoản hiện đang đăng nhập.

    /status
Account: your-email@example.com
Plan: Claude Pro

Troubleshoot

Lỗi: 'claude' is not recognized as an internal or external command
Nguyên nhân: Thư mục global npm (%AppData%\npm) chưa nằm trong biến môi trường PATH, hoặc terminal đang mở từ trước khi cài đặt.
Giải pháp: Đóng và mở lại PowerShell/Windows Terminal. Nếu vẫn lỗi, kiểm tra và thêm thủ công đường dẫn %AppData%\npm vào PATH trong Environment Variables.
Lỗi: Cài đặt Claude Code thất bại do phiên bản Node.js quá cũ.
Nguyên nhân: Claude Code yêu cầu Node.js phiên bản 18 trở lên.
Giải pháp: Chạy winget upgrade OpenJS.NodeJS.LTS hoặc gỡ bản cũ và cài lại bản LTS mới nhất từ nodejs.org.
Lỗi: Trình duyệt không tự mở khi đăng nhập Claude Code.
Nguyên nhân: Máy chưa đặt trình duyệt mặc định, hoặc terminal không có quyền mở ứng dụng ngoài.
Giải pháp: Copy đường link đăng nhập hiển thị trong terminal và dán trực tiếp vào trình duyệt để hoàn tất OAuth.
Lỗi: Không thể kết nối tới claude.ai hoặc api.anthropic.com khi đăng nhập.
Nguyên nhân: Firewall/proxy công ty chặn kết nối outbound tới các domain của Anthropic.
Giải pháp: Liên hệ bộ phận IT để whitelist domain claude.ai, console.anthropic.com và api.anthropic.com.
