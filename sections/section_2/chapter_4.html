2. Làm quen với Claude / Claude Code

Giới thiệu

Claude Code là trợ lý lập trình chạy trực tiếp trên dòng lệnh (Command Line Interface – CLI), được thiết kế để làm việc ngay trong terminal hoặc tích hợp vào IDE (VS Code, JetBrains) thay vì chỉ trò chuyện qua khung chat. Khác với Claude.ai/Claude Desktop App — nơi người dùng hỏi và Claude trả lời bằng văn bản — Claude Code có thể tự đọc, tự sửa file, tự chạy lệnh ngay trên máy hoặc repository của người dùng để hoàn thành một tác vụ lập trình từ đầu đến cuối.

Các tính năng chính

  • Thao tác trực tiếp trên filesystem: đọc, tạo, sửa nhiều file trong project mà không cần copy-paste code qua lại giữa chat và editor.
  • Chạy được lệnh hệ thống: tự thực thi command (build, test, git, package manager...) và đọc kết quả để tự điều chỉnh bước tiếp theo.
  • Làm việc theo vòng lặp agentic: tự lập kế hoạch (Plan), thực hiện (Code), rồi tự kiểm tra lại kết quả (Verify) — không dừng lại sau một câu trả lời như chat thông thường.
  • Nhiều chế độ tương tác: Plan mode (chỉ lên kế hoạch, chưa sửa code), Auto-accept mode (tự động thực hiện thay đổi), hoặc xác nhận từng bước (Accept Edits) tuỳ mức độ tin tưởng.
  • Mở rộng qua Skills, Sub-agent, MCP, Hooks: tuỳ biến hành vi và kết nối thêm hệ thống bên ngoài (sẽ học ở Section 3, 8, 9).
  • Tích hợp Git: tự tạo commit, viết mô tả Pull Request, hỗ trợ code review ngay trong luồng làm việc.

Use Cases

Khởi tạo project mới

Yêu cầu Claude Code dựng sẵn cấu trúc project theo tech stack chỉ định (vd: Next.js, FastAPI) chỉ với một câu lệnh mô tả yêu cầu.

Đọc hiểu codebase lạ

Yêu cầu tóm tắt kiến trúc, luồng dữ liệu của một repository chưa từng biết trước, tiết kiệm thời gian đọc code thủ công.

Thêm tính năng / sửa lỗi

Mô tả yêu cầu bằng ngôn ngữ tự nhiên, Claude Code tự tìm đúng file cần sửa, viết code và kiểm tra lại kết quả.

Refactor & viết test

Tự động refactor đoạn code phức tạp và sinh kèm unit test tương ứng để đảm bảo hành vi không đổi.

Thông tin bổ sung

Vì Claude Code có thể thực thi lệnh và chỉnh sửa file trực tiếp, luôn nên review kỹ các thay đổi trước khi chấp nhận, đặc biệt với lệnh có khả năng gây ảnh hưởng lớn (xoá file, thay đổi cấu hình hệ thống, thao tác Git như force push). Nên bắt đầu với chế độ xác nhận từng bước (Accept Edits) khi mới làm quen, chỉ chuyển sang chế độ tự động (Auto-accept) khi đã tin tưởng vào cách Claude Code xử lý loại tác vụ đó. Chi tiết các chế độ tương tác (Plan/Auto-mode/Accept Edit) sẽ được thực hành kỹ ở bài Lab tiếp theo trong Section này.
