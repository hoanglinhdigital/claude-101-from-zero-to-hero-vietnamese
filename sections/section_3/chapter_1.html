3. Claude Skills & Agent / Claude Skills là gì?

Giới thiệu

Claude Skill là một "gói kỹ năng" đóng gói sẵn — gồm hướng dẫn (instructions), quy trình thao tác, và có thể kèm theo script/tài nguyên bổ sung — giúp Claude Code biết cách thực hiện một loại tác vụ cụ thể một cách nhất quán, mỗi khi tác vụ đó xuất hiện. Thay vì phải giải thích lại từ đầu quy trình làm việc mỗi lần chat, Skill cho phép đóng gói quy trình đó một lần, lưu vào project hoặc vào máy cá nhân, và để Claude Code tự phát hiện, tự gọi khi có yêu cầu phù hợp — không cần phải nhớ và gõ lại hướng dẫn chi tiết mỗi lần.

Các tính năng chính

  • Mỗi Skill là một thư mục riêng chứa file SKILL.md — nơi khai báo tên, mô tả (description) và nội dung hướng dẫn chi tiết cho tác vụ đó.
  • Auto-discovery — Claude Code tự quét toàn bộ Skill có sẵn, đọc phần description trong YAML frontmatter của từng Skill để biết Skill đó "dùng khi nào", không cần tự chọn hay gọi tên Skill.
  • Skill chỉ được nạp toàn bộ nội dung (phần thân file SKILL.md + tài nguyên đi kèm) khi prompt của người dùng thật sự khớp với mô tả — giúp tiết kiệm context, không làm "nặng" system prompt khi không dùng đến.
  • Có thể đặt ở 2 phạm vi: Project-level (.claude/skills/ trong project, chia sẻ được cho cả team qua Git) hoặc User-level (thư mục cấu hình cá nhân, dùng cho mọi project trên máy).
  • Cho phép đóng gói kèm script, template file, hoặc checklist — không chỉ là đoạn hướng dẫn text đơn thuần.

Claude Code chỉ đọc phần description (rất ngắn) của mọi Skill khi khởi động; toàn bộ nội dung chi tiết trong SKILL.md chỉ được nạp vào context khi prompt của người dùng khớp với đúng Skill đó.

Khi nào nên đóng gói thành Skill? Khi một quy trình được lặp lại nhiều lần theo đúng các bước cố định (vd: sinh changelog, format code theo chuẩn riêng, tạo báo cáo theo template), và cần chuẩn hoá để mọi thành viên trong team đều thực hiện giống nhau — thay vì mỗi người mô tả yêu cầu khác nhau mỗi lần.

Use Cases

Sinh changelog chuẩn hoá

Skill đọc git log theo định dạng quy ước, tự phân loại commit (feature/fix/chore) và sinh file CHANGELOG.md nhất quán mỗi lần release.

Format code theo chuẩn riêng

Đóng gói quy tắc format/coding convention đặc thù của team thành Skill, áp dụng nhất quán cho mọi file được yêu cầu format.

Quy trình review chuẩn hoá

Skill chứa checklist review (bảo mật, performance, coding convention) để Claude Code áp dụng đầy đủ mỗi khi được yêu cầu review code.

Sinh tài liệu theo template

Đóng gói template báo cáo/tài liệu kỹ thuật cố định, Skill tự điền nội dung theo đúng cấu trúc mỗi khi cần tạo tài liệu mới.

Thông tin bổ sung

Skill hoạt động tốt nhất khi phần description trong frontmatter được viết rõ ràng, cụ thể về trigger — mô tả đúng những từ khoá, ngữ cảnh mà người dùng thường dùng khi cần tác vụ đó. Description quá mơ hồ khiến Claude Code khó nhận diện đúng lúc, dẫn đến Skill không được gọi dù đúng nhu cầu, hoặc bị gọi sai trong tình huống không liên quan.

Lưu ý: Không nên nhồi quá nhiều Skill có phạm vi mô tả chồng chéo lên nhau — dễ gây nhầm lẫn khi Claude Code chọn Skill để gọi. Mỗi Skill nên tập trung vào một quy trình rõ ràng, tên và description không trùng lặp ý nghĩa với Skill khác trong cùng project.
