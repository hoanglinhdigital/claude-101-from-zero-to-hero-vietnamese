3. Claude Skills & Agent / Lab - Tạo một Claude Sub-Agent

Mục tiêu

  • Tự tạo một Sub-agent chuyên biệt — code-reviewer — chỉ chuyên review chất lượng code, với phạm vi tools và system prompt riêng.
  • Hiểu cách khai báo YAML frontmatter cho Sub-agent: name, description, tools, model.
  • Biết 2 cách gọi Sub-agent: tự động qua trigger trong description, và gọi rõ ràng qua lệnh /agents.
  • Xác nhận được Sub-agent thực sự được Main Agent sử dụng khi review một đoạn code mẫu.

Main Agent phát hiện Sub-agent code-reviewer phù hợp dựa trên description, giao việc qua Task tool; Sub-agent chỉ có quyền đọc (Read/Grep/Glob), tự đọc file code và trả về danh sách finding, không tự sửa file.

Yêu cầu trước khi bắt đầu

  • Claude Code CLI đã cài đặt và đăng nhập thành công (xem lại Section 2).
  • Terminal: PowerShell hoặc Windows Terminal.
  • Có thể dùng lại project D:\lab-claude-skill ở bài Lab trước, hoặc tạo project mới như hướng dẫn dưới đây.

Các bước thực hành

Phần 1: Chuẩn bị project và đoạn code mẫu để review

  1. Bước 1: Tạo thư mục project

    Tạo một project trống dùng để thực hành tạo Sub-agent (hoặc sử dụng lại project của bài lab Skill)

    mkdir D:\lab-claude-subagent
cd D:\lab-claude-subagent
  2. Bước 2: Tạo file code mẫu có vài vấn đề chất lượng

    Tạo file expense.js chứa vài lỗi phổ biến (không kiểm tra input, dùng biến toàn cục, không xử lý lỗi) để Sub-agent có thứ để review.

    expense.js

    Dán nội dung sau vào file rồi lưu (Ctrl+S):

    expense.js// Bien toan cuc luu danh sach khoan chi tieu
var expenses = [];

function addExpense(amount, category) {
    // Khong kiem tra amount co hop le hay khong
    expenses.push({ amount: amount, category: category });
    return "OK";
}

function getTotal() {
    var total = 0;
    for (var i = 0; i <= expenses.length; i++) {
        total = total + expenses[i].amount;
    }
    return total;
}

function deleteExpense(index) {
    expenses.splice(index, 1);
}

Phần 2: Tạo Sub-agent code-reviewer

  1. Bước 3: Tạo thư mục Sub-agent

    Sub-agent được khai báo dưới dạng file Markdown trong thư mục .claude/agents/ ở gốc project.

    mkdir .claude\agents
  2. Bước 4: Viết file code-reviewer.md

    Tạo file code-reviewer.md bên trong thư mục .claude\agents.

    .claude\agents\code-reviewer.md

    Dán nội dung sau vào file rồi lưu (Ctrl+S) — lưu ý phần tools chỉ liệt kê đúng 3 quyền đọc, không có quyền ghi/xoá file hay chạy lệnh:

    .claude/agents/code-reviewer.md---
name: code-reviewer
description: Chuyên gia review chất lượng code. Dùng Sub-agent này khi người dùng yêu cầu "review code", "kiểm tra chất lượng code", "review file", hoặc "đánh giá đoạn code" trước khi merge/commit. Chỉ đọc code, không tự sửa file.
tools: Read, Grep, Glob
model: sonnet
---

Bạn là một Senior Code Reviewer có nhiều năm kinh nghiệm, chuyên trách kiểm tra chất
lượng code trước khi merge. Khi được giao review một file hoặc đoạn code, luôn thực hiện theo quy trình sau:

## Quy trình review
1. Đọc toàn bộ nội dung file được yêu cầu review bằng tool Read.
2. Kiểm tra theo 4 nhóm tiêu chí:
   - **Bug/Logic**: lỗi off-by-one, thiếu kiểm tra input, xử lý sai điều kiện biên.
   - **Bảo mật**: dữ liệu đầu vào không được validate, rủi ro injection.
   - **Coding convention**: dùng `var` thay vì `let/const`, biến toàn cục không cần thiết,
     thiếu xử lý lỗi (try/catch).
   - **Khả năng đọc/maintain**: tên hàm/biến không rõ nghĩa, hàm quá dài, thiếu comment.
3. Với mỗi vấn đề tìm được, trả lời theo format: **[Mức độ] Dòng X — Mô tả vấn đề — Đề xuất sửa**.
   Mức độ gồm: `Critical`, `Warning`, `Suggestion`.
4. Không tự sửa file — chỉ liệt kê finding và đề xuất, để người dùng hoặc Main Agent quyết định
   bước tiếp theo.
5. Nếu không tìm thấy vấn đề nào, xác nhận rõ ràng "Không phát hiện vấn đề đáng chú ý" — không
   bịa ra lỗi không có thật.
Vì sao giới hạn tools chỉ gồm Read, Grep, Glob? Đây là nguyên tắc least privilege đã học ở chương trước — Sub-agent chuyên review chỉ cần đọc và tìm kiếm trong code, không cần quyền ghi/xoá file hay chạy lệnh hệ thống, giảm rủi ro nếu system prompt bị dẫn dắt sai hướng.

Troubleshoot

Lỗi: Main Agent tự review code, không thấy gọi Sub-agent code-reviewer.
Nguyên nhân: Description chưa đủ rõ trigger, hoặc câu hỏi của học viên dùng từ ngữ quá khác so với description đã khai báo.
Giải pháp: Chỉ định rõ tên Sub-agent trong prompt như Bước 8, hoặc chỉnh lại description cho sát với cách học viên thường hỏi.
Lỗi: Lệnh /agents không hiển thị Sub-agent code-reviewer.
Nguyên nhân: File không nằm đúng đường dẫn .claude/agents/code-reviewer.md, hoặc frontmatter YAML bị sai cú pháp (thiếu dấu --- mở/đóng).
Giải pháp: Kiểm tra lại bằng dir .claude\agents, mở lại file và đối chiếu đúng cấu trúc frontmatter ở Bước 4, sau đó khởi động lại phiên Claude Code.
Lỗi: Sub-agent cố gắng sửa trực tiếp file expense.js thay vì chỉ liệt kê finding.
Nguyên nhân: Khai báo tools trong frontmatter bị dư quyền (vd vô tình thêm Edit/Write), hoặc system prompt chưa nêu rõ "không tự sửa file".
Giải pháp: Kiểm tra lại danh sách tools chỉ gồm Read, Grep, Glob, đảm bảo mục 4 trong quy trình review (không tự sửa file) được giữ nguyên trong system prompt.
