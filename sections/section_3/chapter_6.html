3. Claude Skills & Agent / Lab - Custom Slash Command

Mục tiêu

  • Hiểu định nghĩa Custom Slash Command — một prompt được đóng gói thành file Markdown, gọi lại được bằng lệnh /tên-command ngay trong phiên Claude Code.
  • Phân biệt các cách cài đặt: tạo thủ công (project scope hoặc user scope) và cài qua Plugin từ Marketplace.
  • Tự tạo một Custom Slash Command đơn giản, có tham số ($ARGUMENTS), dùng để sinh commit message theo chuẩn Conventional Commits.
  • Cài đặt và sử dụng thử một Slash Command có sẵn từ một Plugin trên Claude Code Marketplace.

So sánh Slash Command và Skill

Cả Slash Command và Skill đều là file Markdown đóng gói sẵn nội dung để tái sử dụng, nhưng khác nhau về cách kích hoạt và mức độ chủ động của Claude khi quyết định dùng chúng.

Yêu cầu trước khi bắt đầu

  • Claude Code CLI đã cài đặt và đăng nhập thành công (xem lại Section 2) — kiểm tra bằng claude --version.
  • Có một project bất kỳ để thực hành, ví dụ tái sử dụng lại D:\lab-claude-skill ở các bài Lab trước, hoặc tạo mới.

Các bước thực hành

Phần 1: Tạo Custom Slash Command thủ công

Custom Slash Command thủ công là một file .md đặt trong thư mục .claude/commands/. Tên file (không tính đuôi .md) chính là tên lệnh gọi sau dấu /. Nội dung file là phần prompt sẽ được gửi cho Claude khi lệnh được gọi, có thể chứa YAML frontmatter (description, argument-hint...) và biến $ARGUMENTS để nhận tham số truyền vào từ dòng lệnh.

  1. Bước 1: Di chuyển vào project sẽ dùng command 
    cd D:\lab-claude-skill
  2. Bước 2: Tạo thư mục chứa command ở project scope

    Command đặt trong .claude/commands/ tại thư mục project chỉ áp dụng cho project này (project scope) — phù hợp khi command gắn liền quy ước riêng của repo, có thể commit vào Git để chia sẻ cho cả team.

    mkdir .claude\commands
  3. Bước 3: Tạo file định nghĩa command commit-msg.md

    Tạo file mới tại .claude/commands/commit-msg.md với nội dung sau. Phần $ARGUMENTS sẽ được thay bằng toàn bộ nội dung học viên gõ sau tên lệnh.

    ---
description: Sinh commit message theo chuẩn Conventional Commits từ mô tả ngắn
argument-hint: [mô tả thay đổi]
---

Dựa trên mô tả sau: "$ARGUMENTS"

Hãy chạy `git diff --staged` để xem thay đổi thực tế đang được staged, sau đó
sinh ra một commit message theo chuẩn Conventional Commits (`feat`, `fix`,
`refactor`, `docs`, `chore`...), gồm:
1. Dòng subject ngắn gọn (dưới 72 ký tự).
2. Một đoạn body 1-2 câu giải thích lý do thay đổi (why), không lặp lại what.

Chỉ in ra commit message, không thực hiện commit.
  4. Bước 4: Khởi động Claude Code và kiểm tra command đã được nhận diện 
    claude
    /help

    Lệnh /commit-msg phải xuất hiện trong danh sách slash command, nằm ở nhóm command của project (đánh dấu (project)).

  5. Bước 5: Thử staged một thay đổi bất kỳ và gọi command 
    git add .
    /commit-msg thêm slash command tạo commit message tự động

    Claude sẽ chạy git diff --staged để đọc thay đổi thực tế, rồi trả về một commit message theo đúng cấu trúc Conventional Commits đã khai báo trong file lệnh.

Project scope vs User scope: File đặt tại .claude/commands/ trong project chỉ dùng được trong project đó (project scope). Nếu muốn command dùng được ở mọi project trên máy, đặt file tại ~/.claude/commands/ (user scope) — cú pháp file giống hoàn toàn, chỉ khác vị trí thư mục.

Phần 2: Cài đặt Slash Command có sẵn từ Plugin trên Marketplace

Ngoài tự viết, học viên có thể cài đặt các Slash Command đã được đóng gói sẵn bên trong một Plugin từ Claude Code Marketplace — tương tự cách cài Skill qua Plugin đã học ở bài trước. Một Plugin có thể chứa nhiều Slash Command, Skill, Sub-agent, Hook cùng lúc.

  1. Bước 6: Đăng ký marketplace chính thức của Anthropic

    Vẫn trong phiên Claude Code tại project D:\lab-claude-skill, đăng ký kho anthropics/skills làm marketplace (nếu chưa đăng ký ở bài Lab trước).

    /plugin marketplace add anthropics/skills
  2. Bước 7: Duyệt danh sách Plugin có kèm Slash Command

    Mở giao diện quản lý Plugin, chuyển sang tab Discover, chọn marketplace anthropic-agent-skills. Chọn một Plugin bất kỳ và nhấn Enter để xem chi tiết — phần Commands trong màn hình chi tiết liệt kê các Slash Command mà Plugin đó cung cấp.

    /plugin
  3. Bước 8: Cài đặt Plugin trực tiếp bằng lệnh

    Ví dụ cài Plugin example-skills — Plugin này minh hoạ cách đóng gói Skill kèm Slash Command.

    /plugin install example-skills@anthropic-agent-skills
  4. Bước 9: Nạp lại Plugin và kiểm tra Slash Command mới 
    /reload-plugins
    /help

    Các Slash Command do Plugin cung cấp sẽ xuất hiện trong danh sách /help, đánh dấu tên Plugin nguồn (ví dụ (plugin: example-skills)). Gọi thử một trong các lệnh đó theo đúng cú pháp và argument-hint hiển thị khi gõ /.

✅ Kết quả mong đợi

Lệnh /help hiển thị đầy đủ cả /commit-msg (tạo thủ công ở Phần 1, đánh dấu project scope) và (các) Slash Command đến từ Plugin vừa cài ở Phần 2. Gọi /commit-msg <mô tả> với một thay đổi đã git add trả về đúng một commit message theo chuẩn Conventional Commits, không thực hiện commit thật.

Troubleshoot

Lỗi: /commit-msg không xuất hiện trong /help sau khi tạo file.
Nguyên nhân: File không nằm đúng đường dẫn .claude/commands/commit-msg.md, sai đuôi file (không phải .md), hoặc phiên Claude Code đang chạy từ trước khi file được tạo.
Giải pháp: Kiểm tra lại bằng dir .claude\commands, đảm bảo tên file khớp tên lệnh muốn gọi, sau đó thoát (/exit) và mở lại phiên Claude Code.
Lỗi: Gọi /commit-msg mô tả gì đó nhưng Claude không thấy nội dung mô tả.
Nguyên nhân: File lệnh thiếu biến $ARGUMENTS, hoặc gõ sai cú pháp (thiếu khoảng trắng giữa tên lệnh và nội dung).
Giải pháp: Mở lại commit-msg.md, xác nhận có dòng chứa $ARGUMENTS, gõ lại đúng dạng /commit-msg nội dung mô tả.
Lỗi: Sau /plugin install, Slash Command của Plugin vẫn không gọi được.
Nguyên nhân: Quên chạy /reload-plugins sau khi cài, nên Plugin chưa được nạp vào phiên hiện tại.
Giải pháp: Chạy /reload-plugins như Bước 9, hoặc thoát và mở lại phiên Claude Code.
Lỗi: Đặt cùng tên command ở cả project scope và user scope, không rõ lệnh nào được ưu tiên.
Nguyên nhân: Command trùng tên được định nghĩa ở nhiều nơi (project, user, hoặc Plugin).
Giải pháp: Claude Code ưu tiên command ở project scope trước user scope; nếu trùng cả với Plugin, nên đổi tên một trong hai để tránh nhầm lẫn — kiểm tra nguồn gốc command đang được dùng qua nhãn hiển thị trong /help.

Dọn dẹp resource

Bài lab này chỉ tạo file cấu hình và đăng ký marketplace trên máy local, không tạo resource cloud, không phát sinh chi phí ngoài usage theo gói cước Claude đang sử dụng. Có thể dọn dẹp nếu không cần dùng tiếp:
# Gỡ Plugin đã cài (chạy trong phiên Claude Code)
/plugin uninstall example-skills@anthropic-agent-skills

# Xoá Slash Command tạo thủ công ở Phần 1 (PowerShell)
Remove-Item -Force D:\lab-claude-skill\.claude\commands\commit-msg.md
