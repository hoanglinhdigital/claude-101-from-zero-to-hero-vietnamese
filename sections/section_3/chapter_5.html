3. Claude Skills & Agent / Lab - Cài đặt Anthropic Skills có sẵn

Mục tiêu

  • Biết đến kho anthropics/skills trên GitHub — nơi Anthropic công bố các Skill mẫu chính thức (document-skills: docx/pptx/xlsx/pdf, example-skills...).
  • Thực hành Phần 1: tải kho Skill về máy và copy trực tiếp Skill cần dùng vào project (cài đặt Skill thuần, không qua Plugin).
  • Thực hành Phần 2: cài đặt Plugin từ Marketplace bằng lệnh /plugin — hiểu rõ đây là cơ chế cài đặt Plugin (có thể gồm Skill, Sub-agent, Hook, MCP server...), khác với việc chỉ copy một Skill đơn thuần.
  • Phân biệt được khi nào nên dùng Skill thuần (Phần 1) và khi nào nên dùng Plugin từ Marketplace (Phần 2).

Phần 1 chỉ copy thẳng thư mục Skill (chỉ có SKILL.md + resources) vào .claude/skills. Phần 2 dùng lệnh /plugin để cài đặt một Plugin — một gói có thể chứa nhiều Skill, Sub-agent, Hook, MCP server cùng lúc, được Claude Code quản lý qua Marketplace (bật/tắt, gỡ, cập nhật phiên bản).

Yêu cầu trước khi bắt đầu

  • Claude Code CLI đã cài đặt và đăng nhập thành công (xem lại Section 2) — khuyến nghị bản mới nhất, dùng claude --version để kiểm tra.
  • Git đã cài đặt trên máy (dùng cho Phần 1) — kiểm tra bằng git --version.
  • Có thể dùng lại project D:\lab-claude-skill ở bài Lab trước (Section 3, Chapter 2), hoặc tạo project mới như hướng dẫn dưới đây.

Các bước thực hành

Phần 1: Cài đặt Skill thông qua Anthropic GitHub Official Repository

  1. Bước 1: Di chuyển vào project sẽ dùng Skill

    Tái sử dụng lại project D:\lab-claude-skill đã tạo ở bài Lab trước. Nếu chưa có, tạo mới một thư mục project trống.

    cd D:\lab-claude-skill
  2. Bước 2: Clone kho anthropics/skills về một thư mục riêng

    Không clone trực tiếp vào project — tải kho về một thư mục tạm bên ngoài, sau đó chỉ copy đúng Skill cần dùng vào project.

    cd D:\
git clone https://github.com/anthropics/skills.git anthropic-skills-repo
cd anthropic-skills-repo
dir
  3. Bước 3: Xem danh sách Skill có sẵn trong kho

    Mỗi Skill nằm trong một thư mục riêng, chứa file SKILL.md khai báo frontmatter (name, description) giống cấu trúc đã học ở Chapter 2. Kho được tổ chức theo nhóm, ví dụ:

    dir
document-skills   # docx, pptx, xlsx, pdf
example-skills    # các Skill ví dụ, minh hoạ cách xây dựng Skill
artifacts-builder
  4. Bước 4: Tạo thư mục Skill trong project nếu chưa có 
    cd D:\lab-claude-skill
mkdir .claude\skills
  5. Bước 5: Copy Skill cần dùng vào project

    Ví dụ copy Skill docx (tạo/chỉnh sửa file Word) từ nhóm document-skills trong kho vừa clone vào thư mục Skill của project.

    Copy-Item -Path D:\anthropic-skills-repo\document-skills\docx -Destination D:\lab-claude-skill\.claude\skills\docx -Recurse
  6. Bước 6: Kiểm tra Skill đã được nhận diện

    Khởi động lại Claude Code trong project (nếu đang chạy sẵn, gõ /exit rồi mở lại) và dùng slash command /skills để xem danh sách Skill hiện có — docx phải xuất hiện trong danh sách.

    claude
    /skills
Vì sao không clone thẳng kho vào .claude/skills? Kho anthropics/skills chứa rất nhiều Skill khác nhau — Claude Code sẽ cố gắng đọc tất cả thư mục con như từng Skill riêng biệt, gây nhiễu context và làm chậm quá trình phát hiện Skill phù hợp. Luôn chỉ copy đúng (những) Skill thật sự cần dùng.

Phần 2: Cài đặt plugin từ marketplace

Lệnh /plugin không cài đặt một Skill đơn lẻ — nó cài đặt một Plugin, tức một gói mở rộng có thể đóng gói nhiều thành phần cùng lúc: Skill, Sub-agent, Hook, Slash command và cả MCP server. Kho anthropics/skills cũng đồng thời được công bố dưới dạng một Plugin Marketplace tên anthropic-agent-skills, cho phép cài đặt các Skill của Anthropic dưới hình thức Plugin thay vì copy tay như Phần 1.

  1. Bước 7: Đăng ký repository làm Plugin Marketplace

    Trong phiên Claude Code (vẫn ở project D:\lab-claude-skill), dùng lệnh /plugin marketplace add kèm tên repo GitHub dạng owner/repo để đăng ký kho anthropics/skills làm nguồn marketplace.

    /plugin marketplace add anthropics/skills

    Claude Code sẽ tải metadata của marketplace về và đăng ký nó dưới tên anthropic-agent-skills.

  2. Bước 8: Xem danh sách Plugin có thể cài đặt

    Mở giao diện quản lý plugin để duyệt danh sách các Plugin có trong marketplace vừa thêm. Giao diện gồm 4 tab, chuyển bằng Tab/Shift+Tab: Discover (khám phá plugin mới), Installed (plugin đã cài), Marketplaces (quản lý marketplace) và Errors (lỗi tải plugin).

    /plugin

    Ở tab Discover, chọn marketplace anthropic-agent-skills, dùng phím mũi tên để chọn plugin (ví dụ document-skills), nhấn Enter để xem chi tiết (gồm những Skill/Agent/Hook plugin sẽ cài) rồi chọn phạm vi cài đặt (User/Project/Local scope) để xác nhận.

  3. Bước 9: Cài đặt Plugin trực tiếp bằng lệnh

    Có thể bỏ qua giao diện tương tác và cài thẳng Plugin nếu đã biết tên plugin và marketplace, theo cú pháp /plugin install <plugin-name>@<marketplace-name>.

    /plugin install document-skills@anthropic-agent-skills

    Có thể cài thêm Plugin example-skills (các Skill ví dụ) theo cùng cú pháp:

    /plugin install example-skills@anthropic-agent-skills
  4. Bước 10: Kích hoạt Plugin vừa cài trong phiên hiện tại

    Sau khi cài đặt, chạy /reload-plugins để Claude Code nạp lại toàn bộ Skill/Agent/Hook/MCP server của Plugin mà không cần khởi động lại phiên.

    /reload-plugins
  5. Bước 11: Xác nhận Plugin đã cài đặt thành công

    Kiểm tra danh sách Plugin đã cài và danh sách Skill hiện có trong phiên.

    /plugin list --enabled
    /skills

    Danh sách trả về phải có cả Skill cài qua Phần 1 (docx, copy thủ công) lẫn Plugin cài qua Phần 2 (document-skills, example-skills, qua Plugin Marketplace).

✅ Kết quả mong đợi

Lệnh /plugin list --enabled hiển thị document-skills và example-skills ở trạng thái đã cài đặt, lệnh /skills hiển thị đầy đủ Skill từ cả 2 nguồn (copy thủ công lẫn qua Plugin), và khi gõ một yêu cầu liên quan (vd "tạo giúp tôi một file Word tóm tắt nội dung sau") Claude Code tự động dùng đúng Skill tương ứng.

Troubleshoot

Lỗi: Lệnh git clone báo lỗi 'git' is not recognized.
Nguyên nhân: Git chưa được cài đặt hoặc chưa có trong biến môi trường PATH.
Giải pháp: Cài đặt Git for Windows từ trang chủ chính thức, khởi động lại terminal sau khi cài, kiểm tra lại bằng git --version.
Lỗi: Lệnh /skills không hiển thị Skill vừa copy ở Phần 1.
Nguyên nhân: Thư mục Skill không nằm đúng đường dẫn .claude/skills/<tên-skill>/SKILL.md, hoặc phiên Claude Code chưa được khởi động lại sau khi copy.
Giải pháp: Kiểm tra lại bằng dir .claude\skills, đảm bảo file SKILL.md nằm ngay trong thư mục Skill, sau đó thoát và mở lại phiên Claude Code.
Lỗi: /plugin marketplace add anthropics/skills báo lỗi không tải được marketplace.
Nguyên nhân: Mất kết nối Internet, gõ sai định dạng tên repo (phải đúng dạng owner/repo), hoặc Claude Code phiên bản cũ chưa hỗ trợ đầy đủ lệnh /plugin.
Giải pháp: Kiểm tra lại kết nối mạng, đối chiếu chính xác tên repo trên GitHub, cập nhật Claude Code lên bản mới nhất (npm install -g @anthropic-ai/claude-code@latest) rồi thử lại.
Lỗi: /plugin install document-skills@anthropic-agent-skills báo lỗi Marketplace not found.
Nguyên nhân: Marketplace chưa được đăng ký thành công ở Bước 7, hoặc dữ liệu marketplace trên máy đã cũ.
Giải pháp: Chạy lại /plugin marketplace add anthropics/skills, hoặc làm mới dữ liệu bằng /plugin marketplace update anthropic-agent-skills rồi cài lại.
Lỗi: Sau khi cài Plugin, gõ yêu cầu liên quan nhưng Claude Code không dùng Skill trong Plugin.
Nguyên nhân: Quên chạy /reload-plugins sau khi cài, nên Plugin chưa được nạp vào phiên hiện tại.
Giải pháp: Chạy /reload-plugins như Bước 10, hoặc thoát và mở lại phiên Claude Code.
Lỗi: Cài cả Skill thủ công (Phần 1) lẫn Plugin (Phần 2) cho cùng một chức năng khiến Claude Code chọn nhầm.
Nguyên nhân: Description của Skill (Phần 1) và Skill trong Plugin (Phần 2) quá giống nhau, Claude Code không phân biệt được nên dùng bản nào.
Giải pháp: Chỉ giữ lại một nguồn duy nhất cho mỗi chức năng — gỡ Plugin bằng /plugin uninstall document-skills@anthropic-agent-skills hoặc xoá thư mục tương ứng trong .claude/skills (Phần 1).

Dọn dẹp resource

Bài lab này chỉ tạo file, thư mục và đăng ký marketplace trên máy local, không tạo ra resource cloud nào và không phát sinh chi phí ngoài usage theo gói cước Claude đang sử dụng. Có thể dọn dẹp nếu không cần dùng tiếp:
# Gỡ từng Plugin đã cài (chạy trong phiên Claude Code)
/plugin uninstall document-skills@anthropic-agent-skills
/plugin uninstall example-skills@anthropic-agent-skills

# Gỡ đăng ký marketplace — lưu ý thao tác này sẽ tự gỡ luôn mọi Plugin cài từ marketplace này
/plugin marketplace remove anthropic-agent-skills
# Xoá thư mục kho đã clone tạm (Powershell):
Remove-Item -Recurse -Force D:\anthropic-skills-repo

# Xoá Skill đã copy thủ công trong project (nếu không cần dùng tiếp) (Powershell):
Remove-Item -Recurse -Force D:\lab-claude-skill\.claude\skills\docx
